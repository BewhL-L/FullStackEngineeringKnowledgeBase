# 数据结构与算法知识点系统梳理

> 本文档按"概念+原理+代码+场景+坑点"五要素深度梳理算法与数据结构核心知识，每个知识点配 Python 实现、面试考点、常见坑点与梯度练习。

## 一、算法复杂度分析

### 1.1 时间复杂度

**概念**：算法执行时间随输入规模 n 增长的趋势，用大 O 表示。

**原理**：只看最高阶项，忽略常数和低阶。常见：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。

```python
# O(1)
def f1():
    return 42

# O(n)
def f2(n):
    for i in range(n):
        pass

# O(n²)
def f3(n):
    for i in range(n):
        for j in range(n):
            pass

# O(log n) 二分
def f4(n):
    while n > 1:
        n //= 2
```

### 1.2 空间复杂度

**概念**：额外空间随 n 增长。递归栈也算。

```python
# O(n) 递归
def sum(n):
    if n == 0: return 0
    return n + sum(n-1)   # 栈 O(n)

# O(1) 迭代
def sum2(n):
    return n * (n + 1) // 2
```

### 1.3 主定理

T(n) = aT(n/b) + f(n)，用来求分治递归复杂度。

```
T(n) = 2T(n/2) + O(n)  → O(n log n) 归并排序
T(n) = T(n/2) + O(1)   → O(log n) 二分
T(n) = 2T(n/2) + O(1)  → O(n) 二叉树遍历
```

### 1.4 最好/最坏/平均

```python
# 最好 O(1)（第一个就找到），最坏 O(n)
def linear_search(arr, x):
    for i, v in enumerate(arr):
        if v == x: return i
    return -1
```

### 1.5 复杂度速查表

| 复杂度 | 例子 |
|--------|------|
| O(1) | 哈希查找 |
| O(log n) | 二分 |
| O(n) | 遍历 |
| O(n log n) | 快排归并 |
| O(n²) | 冒泡选择 |
| O(2ⁿ) | 斐波那契递归 |
| O(n!) | 全排列 |

> 💡 **深度讲解**：复杂度分析是算法的"语言"。面试先报复杂度。对数的底数在大 O 里不重要（常数因子）。
>
> 📝 **总结**：时间+空间复杂度，只看最高阶。递归有栈开销。
>
> 🎯 **练习**：⭐ 求嵌套循环 O(n log n)；⭐⭐ 用主定理求 T(n)=4T(n/2)+O(n)；⭐⭐⭐ 分析动态规划的复杂度。


## 二、数组与链表

### 2.1 数组

**概念**：连续内存，随机访问 O(1)，插入删除 O(n)。

```python
arr = [1, 2, 3]
arr.append(4)       # 尾部 O(1) 均摊
arr.insert(0, 0)    # 头部 O(n)
arr.pop()           # 尾部 O(1)
```

### 2.2 数组典型问题

**两数之和**：

```python
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target-n], i]
        seen[n] = i
# O(n) 哈希法
```

**反转数组**：

```python
def reverse(arr):
    l, r = 0, len(arr)-1
    while l < r:
        arr[l], arr[r] = arr[r], arr[l]
        l += 1; r -= 1
```

### 2.3 链表

**概念**：节点+指针，插入删除 O(1)，访问 O(n)。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# 反转链表
def reverse(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

### 2.4 链表典型问题

**环检测**（快慢指针）：

```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False
```

**合并两个有序链表**：

```python
def merge(l1, l2):
    dummy = ListNode()
    p = dummy
    while l1 and l2:
        if l1.val < l2.val:
            p.next = l1; l1 = l1.next
        else:
            p.next = l2; l2 = l2.next
        p = p.next
    p.next = l1 or l2
    return dummy.next
```

**中间节点**：

```python
def middle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
```

### 2.5 数组 vs 链表

| 维度 | 数组 | 链表 |
|------|------|------|
| 访问 | O(1) | O(n) |
| 插入 | O(n) | O(1) |
| 内存 | 连续 | 散 |
| 缓存 | 友好 | 差 |

> 💡 **深度讲解**：数组连续内存缓存友好，链表指针跳来跳去缓存不友好。实际工程数组性能往往更好，除非频繁插删。
>
> 📝 **总结**：数组随机访问快，链表插删快。快慢指针是链表神器。
>
> 🎯 **练习**：⭐ 反转链表；⭐⭐ K个一组反转；⭐⭐⭐ 链表排序。

### 3.1 栈

**概念**：后进先出 LIFO。Python list 即可。

### 3.2 栈应用

**括号匹配**：

```python
def is_valid(s):
    pair = {')':'(', ']':'[', '}':'{'}
    stack = []
    for c in s:
        if c in pair:
            if not stack or stack.pop() != pair[c]:
                return False
        else:
            stack.append(c)
    return not stack
```

**单调栈**（下一个更大元素）：

```python
def next_greater(nums):
    stack = []
    res = [-1] * len(nums)
    for i, n in enumerate(nums):
        while stack and nums[stack[-1]] < n:
            res[stack.pop()] = n
        stack.append(i)
    return res
```

### 3.4 队列应用

**BFS**：

```python
from collections import deque
def bfs(root):
    if not root: return []
    q = deque([root])
    res = []
    while q:
        node = q.popleft()
        res.append(node.val)
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    return res
```

**循环队列**：

```python
class MyCircularQueue:
    def __init__(self, k):
        self.q = [0]*k
        self.head = self.count = 0
        self.cap = k
    def enQueue(self, v):
        if self.isFull(): return False
        self.q[(self.head+self.count)%self.cap] = v
        self.count += 1
        return True
    def deQueue(self):
        if self.isEmpty(): return False
        self.head = (self.head+1)%self.cap
        self.count -= 1
        return True
    def isEmpty(self): return self.count == 0
    def isFull(self): return self.count == self.cap
```

### 3.5 单调栈与单调队列

单调栈：求"下一个更大/更小"。单调队列：求滑动窗口最大。

```python
from collections import deque
def max_sliding(nums, k):
    dq = deque()
    res = []
    for i, n in enumerate(nums):
        while dq and nums[dq[-1]] < n:
            dq.pop()
        dq.append(i)
        if dq[0] <= i-k:
            dq.popleft()
        if i >= k-1:
            res.append(nums[dq[0]])
    return res
```

> 💡 **深度讲解**：单调栈/队列是面试高频。记住"维护一个单调序列，弹出破坏单调性的"。
>
> 📝 **总结**：栈 LIFO、队列 FIFO。单调栈求更大元素，单调队列求滑动窗口。
>
> 🎯 **练习**：⭐ 括号匹配；⭐⭐ 每日温度；⭐⭐⭐ 接雨水（单调栈）。

**最长无重复子串**：

```python
def longest(s):
    seen = {}
    l = ans = 0
    for r, c in enumerate(s):
        if c in seen and seen[c] >= l:
            l = seen[c] + 1
        seen[c] = r
        ans = max(ans, r-l+1)
    return ans
```

## 五、树与二叉树

### 5.1 二叉树遍历

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# 前序（根左右）
def preorder(root):
    if not root: return []
    return [root.val] + preorder(root.left) + preorder(root.right)

# 中序（左根右）BST 有序
def inorder(root):
    if not root: return []
    return inorder(root.left) + [root.val] + inorder(root.right)

# 后序（左右根）
def postorder(root):
    if not root: return []
    return postorder(root.left) + postorder(root.right) + [root.val]

# 层序 BFS
def levelorder(root):
    from collections import deque
    if not root: return []
    q = deque([root])
    res = []
    while q:
        node = q.popleft()
        res.append(node.val)
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
    return res
```

### 5.2 BST 二叉搜索树

左 < 根 < 右。中序遍历有序。

```python
def search_bst(root, val):
    if not root: return None
    if root.val == val: return root
    if val < root.val: return search_bst(root.left, val)
    return search_bst(root.right, val)

def insert_bst(root, val):
    if not root: return TreeNode(val)
    if val < root.val: root.left = insert_bst(root.left, val)
    else: root.right = insert_bst(root.right, val)
    return root
```

### 5.3 平衡二叉树

**AVL**：左右子树高度差 ≤1，旋转平衡。
**红黑树**：近似平衡，插入删除旋转少。Java TreeMap、Linux 进程调度用红黑树。

### 5.4 树的典型问题

**最大深度**：

```python
def max_depth(root):
    if not root: return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))
```

**镜像二叉树**：

```python
def mirror(root):
    if not root: return None
    root.left, root.right = mirror(root.right), mirror(root.left)
    return root
```

**路径总和**：

```python
def has_path_sum(root, target):
    if not root: return False
    if not root.left and not root.right:
        return root.val == target
    return (has_path_sum(root.left, target-root.val) or
            has_path_sum(root.right, target-root.val))
```

### 5.5 遍历复杂度

前/中/后/层序都是 O(n)。递归隐式栈 O(h)，h 最坏 n。

> 💡 **深度讲解**：二叉树题目 90% 用递归想——定义好递归函数（返回什么、对当前节点做什么）。
>
> 📝 **总结**：四种遍历、BST、AVL/红黑树、最大深度。
>
> 🎯 **练习**：⭐ 前序遍历；⭐⭐ 验证BST；⭐⭐⭐ 最近公共祖先。


## 六、堆与优先队列

### 6.1 概念

**原理**：完全二叉树，堆顶最值。Python `heapq` 是最小堆。O(log n) 插入/取顶。

```python
import heapq
h = []
heapq.heappush(h, 3)
heapq.heappush(h, 1)
heapq.heappush(h, 2)
print(heapq.heappop(h))   # 1
```

### 6.2 堆应用

**Top K 大**：

```python
import heapq
def top_k(nums, k):
    return heapq.nlargest(k, nums)

def bottom_k(nums, k):
    return heapq.nsmallest(k, nums)
```

**第 K 大元素**：

```python
def kth_largest(nums, k):
    h = nums[:k]
    heapq.heapify(h)
    for n in nums[k:]:
        if n > h[0]:
            heapq.heapreplace(h, n)
    return h[0]
```

**合并 K 个有序链表**：

```python
def merge_k(lists):
    import heapq
    heap = []
    for i, l in enumerate(lists):
        if l:
            heapq.heappush(heap, (l.val, i, l))
    dummy = ListNode()
    p = dummy
    while heap:
        val, i, node = heapq.heappop(heap)
        p.next = node
        p = p.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next
```

## 七、图论基础

### 7.1 图表示

邻接表：

```python
graph = {
    1: [2, 3],
    2: [4],
    3: [4],
    4: []
}
```

### 7.2 BFS

```python
from collections import deque
def bfs(graph, start):
    visited = {start}
    q = deque([start])
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nb in graph[node]:
            if nb not in visited:
                visited.add(nb)
                q.append(nb)
    return order
```

### 7.3 DFS

```python
def dfs(graph, start, visited=None):
    if visited is None: visited = set()
    visited.add(start)
    for nb in graph[start]:
        if nb not in visited:
            dfs(graph, nb, visited)
    return visited
```

### 7.4 最短路径：Dijkstra

```python
import heapq
def dijkstra(graph, start):
    dist = {start: 0}
    heap = [(0, start)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist.get(u, float('inf')):
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist.get(v, float('inf')):
                dist[v] = dist[u] + w
                heapq.heappush(heap, (dist[v], v))
    return dist
# 复杂度 O(E log V)
```

### 7.5 最小生成树：Kruskal

```python
def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    cost = 0
    for u, v, w in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            cost += w
    return cost
```

### 7.6 拓扑排序

```python
from collections import deque
def topo(n, edges):
    indeg = [0]*n
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i]==0])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order
```

### 7.7 复杂度

| 算法 | 复杂度 |
|------|--------|
| BFS/DFS | O(V+E) |
| Dijkstra | O(E log V) |
| Kruskal | O(E log E) |
| 拓扑 | O(V+E) |

> 💡 **深度讲解**：BFS 找最短边数，DFS 找连通性。Dijkstra 单源最短。Kruskal MST。拓扑排 DAG。
>
> 📝 **总结**：BFS/DFS、Dijkstra、Kruskal、拓扑。
>
> 🎯 **练习**：⭐ BFS；⭐⭐ Dijkstra；⭐⭐⭐ 课程表拓扑排序。


## 八、排序算法

### 8.1 冒泡排序

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
# O(n²) 稳定
```

### 8.2 选择排序

```python
def select_sort(arr):
    n = len(arr)
    for i in range(n):
        mn = i
        for j in range(i+1, n):
            if arr[j] < arr[mn]:
                mn = j
        arr[i], arr[mn] = arr[mn], arr[i]
    return arr
# O(n²) 不稳定
```

### 8.3 插入排序

```python
def insert_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j+1] = arr[j]
            j -= 1
        arr[j+1] = key
    return arr
# O(n²) 稳定，小数组快
```

### 8.4 快速排序

```python
def quick_sort(arr):
    if len(arr) <= 1: return arr
    pivot = arr[len(arr)//2]
    left = [x for x in arr if x < pivot]
    mid = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
# 平均 O(n log n)，最坏 O(n²)，不稳定
```

### 8.5 归并排序

```python
def merge_sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr)//2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(l, r):
    res, i, j = [], 0, 0
    while i < len(l) and j < len(r):
        if l[i] < r[j]:
            res.append(l[i]); i += 1
        else:
            res.append(r[j]); j += 1
    return res + l[i:] + r[j:]
# O(n log n) 稳定
```

### 8.6 堆排序

```python
import heapq
def heap_sort(arr):
    heapq.heapify(arr)
    return [heapq.heappop(arr) for _ in range(len(arr))]
# O(n log n) 不稳定
```

### 8.7 排序算法对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| 冒泡 | n² | n² | 1 | ✅ |
| 选择 | n² | n² | 1 | ❌ |
| 插入 | n² | n² | 1 | ✅ |
| 快排 | n log n | n² | log n | ❌ |
| 归并 | n log n | n log n | n | ✅ |
| 堆排 | n log n | n log n | 1 | ❌ |

> 💡 **深度讲解**：工程用快排（Python sort 是 Timsort 混合）。稳定排序用归并。小规模用插入。
>
> 📝 **总结**：六种排序，快排归并 O(n log n)。
>
> 🎯 **练习**：⭐ 冒泡；⭐⭐ 快排优化（随机pivot）；⭐⭐⭐ 链表归并排序。


## 九、查找算法

### 9.1 二分查找

```python
def binary_search(arr, target):
    l, r = 0, len(arr)-1
    while l <= r:
        mid = (l + r) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return -1
# O(log n) 前提有序
```

```python
def search_rotated(arr, target):
```

### 10.5 零钱兑换

```python
def coin_change(coins, amount):

    dp[0] = 0
    for i in range(1, amount+1):
        for c in coins:
            if c <= i:
                dp[i] = min(dp[i], dp[i-c]+1)
```

### 10.6 最长递增子序列

```python
def lis(nums):
    tails = []
    for n in nums:
        l, r = 0, len(tails)
        while l < r:
            mid = (l+r)//2
            if tails[mid] < n: l = mid+1
            else: r = mid
        if l == len(tails): tails.append(n)
        else: tails[l] = n
    return len(tails)
# O(n log n)
```

### 10.7 背包问题

**01背包**：

```python
def knapsack(w, v, W):
    n = len(w)
    dp = [[0]*(W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for j in range(W+1):
            dp[i][j] = dp[i-1][j]
            if j >= w[i-1]:
                dp[i][j] = max(dp[i][j], dp[i-1][j-w[i-1]]+v[i-1])
    return dp[n][W]
```

```python
    intervals.sort(key=lambda x: x[1])   # 按结束时间

    end = intervals[0][1]
```

### 11.2 回溯算法

**概念**：DFS + 撤销选择。模板：选择→递归→撤销。

**全排列**：

```python
def permute(nums):
    res = []
    def backtrack(path, used):
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i, n in enumerate(nums):
            if used[i]: continue
            used[i] = True
            path.append(n)
            backtrack(path, used)
            path.pop()
            used[i] = False
    backtrack([], [False]*len(nums))
    return res
```

**子集**：

```python
def subsets(nums):
    res = []
    def backtrack(start, path):
        res.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i+1, path)
            path.pop()
    backtrack(0, [])
    return res
```

**N 皇后**：

```python
def solve_nqueens(n):
    res = []
    def backtrack(row, cols, diag1, diag2, board):
        if row == n:
            res.append(["".join(r) for r in board])
            return
        for c in range(n):
            if c in cols or (row-c) in diag1 or (row+c) in diag2:
                continue
            cols.add(c); diag1.add(row-c); diag2.add(row+c)
            board[row][c] = 'Q'
            backtrack(row+1, cols, diag1, diag2, board)
            board[row][c] = '.'
            cols.remove(c); diag1.remove(row-c); diag2.remove(row+c)
    backtrack(0, set(), set(), set(), [['.']*n for _ in range(n)])
    return res
```

### 11.3 分治算法

**概念**：分→治→合。

**归并排序**就是分治。

**快速幂**：

```python
def pow(x, n):
    if n == 0: return 1
    if n < 0: return 1/pow(x, -n)
    half = pow(x, n//2)
    if n % 2 == 0:
        return half * half
    return half * half * x
# O(log n)
```

## 十二、字符串算法

### 12.1 KMP

**原理**：利用已匹配信息，失败时只回退模式串。O(n+m)。

```python
def build_next(p):
    nxt = [0]*len(p)
    j = 0
    for i in range(1, len(p)):
        while j > 0 and p[i] != p[j]:
            j = nxt[j-1]
        if p[i] == p[j]:
            j += 1
        nxt[i] = j
    return nxt

def kmp(s, p):
    if not p: return 0
    nxt = build_next(p)
    j = 0
    for i, c in enumerate(s):
        while j > 0 and c != p[j]:
            j = nxt[j-1]
        if c == p[j]:
            j += 1
        if j == len(p):
            return i - j + 1
    return -1
```

```python
class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        node = self.root
        for c in word:
            node = node.setdefault(c, {})
        node['#'] = True

    def search(self, word):
        node = self.root
        for c in word:
            if c not in node: return False
            node = node[c]
        return '#' in node

    def starts_with(self, prefix):
        node = self.root
        for c in prefix:
            if c not in node: return False
            node = node[c]
        return True
```

```python
class UnionFind:

        self.parent = list(range(n))
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x
    def union(self, a, b):
        self.parent[self.find(a)] = self.find(b)
    def connected(self, a, b):
        return self.find(a) == self.find(b)
```

```python
def three_sum(nums):
    nums.sort()
    res = []
    for i in range(len(nums)-2):
        if i > 0 and nums[i] == nums[i-1]: continue
        l, r = i+1, len(nums)-1
        while l < r:
            s = nums[i]+nums[l]+nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l]==nums[l+1]: l+=1
                while l < r and nums[r]==nums[r-1]: r-=1
                l += 1; r -= 1
            elif s < 0: l += 1
            else: r -= 1
    return res
```

```python
    need = Counter(t)
    missing = len(t)
    l = start = end = 0
    for r, c in enumerate(s, 1):
        if need[c] > 0: missing -= 1
        need[c] -= 1

                need[s[l]] += 1; l += 1
```

### 18.22 LRU 缓存

```python
class LRUCache:
    def __init__(self, capacity):
        self.d = {}
        self.cap = capacity
        self.head = self.Node(0, 0)
        self.tail = self.Node(0, 0)
        self.head.next = self.tail
        self.tail.prev = self.head
    class Node:
        def __init__(self, k, v):
            self.key = k; self.val = v
            self.prev = self.next = None
    def get(self, key):
        if key not in self.d: return -1
        node = self.d[key]
        self._remove(node)
        self._add(node)
        return node.val
    def put(self, key, value):
        if key in self.d:
            self.d[key].val = value
            self._remove(self.d[key])
            self._add(self.d[key])
        else:
            node = self.Node(key, value)
            self.d[key] = node
            self._add(node)
            if len(self.d) > self.cap:
                lru = self.head.next
                self._remove(lru)
                del self.d[lru.key]
    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev
    def _add(self, node):
        node.prev = self.tail.prev
        node.next = self.tail
        self.tail.prev.next = node
        self.tail.prev = node
```

### 18.161 LRU 缓存

```python
class LRU:
    def __init__(self, cap):
        self.cap = cap
        self.d = {}
        self.head = self.Node(0,0)
        self.tail = self.Node(0,0)
        self.head.next = self.tail
        self.tail.prev = self.head
    class Node:
        def __init__(self, k, v):
            self.key = k; self.val = v
            self.prev = self.next = None
    def get(self, key):
        if key not in self.d: return -1
        n = self.d[key]
        self._remove(n); self._add(n)
        return n.val
    def put(self, key, val):
        if key in self.d:
            self.d[key].val = val
            n = self.d[key]
            self._remove(n); self._add(n)
        else:
            n = self.Node(key, val)
            self.d[key] = n; self._add(n)
            if len(self.d) > self.cap:
                lru = self.head.next
                self._remove(lru); del self.d[lru.key]
    def _remove(self, n):
        n.prev.next = n.next; n.next.prev = n.prev
    def _add(self, n):
        n.prev = self.tail.prev; n.next = self.tail
        self.tail.prev.next = n; self.tail.prev = n
```

```python
        if grid[0][j] == 1: break
        dp[0][j] = 1
    for i in range(1, m):
        for j in range(1, n):
            if grid[i][j] == 1: continue
            dp[i][j] = dp[i-1][j]+dp[i][j-1]
    return dp[m-1][n-1]
```

```python
        for j in range(n):
            if matrix[i][j] == '1':
                if i == 0 or j == 0: dp[i][j] = 1
                else: dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])+1
                ans = max(ans, dp[i][j])
    return ans*ans
```

```python
def length_of_lis(nums):
    tails = []
    for n in nums:
        l, r = 0, len(tails)
        while l < r:
            mid = (l+r)//2
            if tails[mid] < n: l = mid+1
            else: r = mid
        if l == len(tails): tails.append(n)
        else: tails[l] = n
    return len(tails)
```

### 18.200 最长回文子串

```python
def longest_palindrome(s):
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        return s[l+1:r]
    res = ""
    for i in range(len(s)):
        p1 = expand(i, i); p2 = expand(i, i+1)
        res = max(res, p1, p2, key=len)
    return res
```
