# 算法复杂度分析

> 算法复杂度的基础概念：时间复杂度、空间复杂度、常见复杂度等级、分析方法、面试常考。

## 概述

算法复杂度分析是评估算法效率的方法，不依赖具体硬件和编程语言，用数学方法描述算法运行时间和空间随输入规模增长的变化趋势。

**为什么需要复杂度分析**：
- 不同算法在相同输入下效率可能差几个数量级
- 事后统计（跑代码看时间）依赖硬件和数据，不可靠
- 复杂度分析可以在写代码前评估算法优劣
- 面试必考，考察工程思维和问题分析能力

**两个维度**：
- **时间复杂度**：算法执行时间随输入规模增长的趋势
- **空间复杂度**：算法所需额外空间随输入规模增长的趋势

## 原理

### 大 O 表示法

大 O 表示法描述算法复杂度的上界，只关注最高阶项，忽略常数系数和低阶项。

**常见复杂度等级（从快到慢）**：

| 复杂度 | 名称 | 示例 | 说明 |
|--------|------|------|------|
| O(1) | 常数阶 | 数组下标访问 | 最快，与输入规模无关 |
| O(log n) | 对数阶 | 二分查找 | 每次规模减半 |
| O(n) | 线性阶 | 遍历数组 | 与输入规模成正比 |
| O(n log n) | 线性对数阶 | 快速排序、归并排序 | 排序算法的最优下界 |
| O(n²) | 平方阶 | 冒泡排序、双重循环 | 小规模可用，大规模慢 |
| O(n³) | 立方阶 | 三重循环 | 很少用，非常慢 |
| O(2ⁿ) | 指数阶 | 斐波那契递归 | 爆炸式增长，不可用 |
| O(n!) | 阶乘阶 | 全排列 | 最慢，n=20就无法计算 |

**复杂度对比图（n=1000）**：
```text
O(1)        = 1
O(log n)    = 10
O(n)        = 1000
O(n log n)  = 10000
O(n²)       = 1000000
O(2ⁿ)       = 10^301 （无法计算）
```

### 时间复杂度分析方法

**规则1：只看最高阶项**
```text
T(n) = 3n² + 2n + 100  →  O(n²)
T(n) = n + log n + 5    →  O(n)
T(n) = 2n * log n       →  O(n log n)
```

**规则2：嵌套循环相乘**
```python
for i in range(n):          # O(n)
    for j in range(n):      # O(n)
        print(i, j)         # O(1)
# 总复杂度：O(n) * O(n) * O(1) = O(n²)
```

**规则3：并列循环相加**
```python
for i in range(n):          # O(n)
    print(i)
for j in range(n*n):        # O(n²)
    print(j)
# 总复杂度：O(n) + O(n²) = O(n²)（取最高阶）
```

**规则4：递归分析**
```python
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)
# 递归树：每层节点数翻倍，深度n → O(2ⁿ)
```

### 空间复杂度分析

空间复杂度只算额外空间，不算输入本身。

```python
def sum_array(arr):
    total = 0               # O(1) 额外空间
    for x in arr:
        total += x
    return total
# 空间复杂度：O(1)

def duplicate_array(arr):
    new_arr = arr.copy()    # O(n) 额外空间
    return new_arr
# 空间复杂度：O(n)
```

**常见空间复杂度**：
- O(1)：几个变量
- O(n)：数组、哈希表
- O(n²)：二维数组、矩阵
- O(log n)：递归调用栈（二分查找递归）
- O(h)：树的高度（递归遍历）

### 最好、最坏、平均情况

```python
def search(arr, target):
    for x in arr:
        if x == target:
            return True
    return False

# 最好情况：第一个就是 → O(1)
# 最坏情况：最后一个或不存在 → O(n)
# 平均情况：假设概率均等 → O(n)
```
通常说的时间复杂度指**最坏情况**，因为它保证了算法的性能上限。

## 实操

### 1. 常见数据结构操作复杂度

| 数据结构 | 查找 | 插入 | 删除 | 说明 |
|---------|------|------|------|------|
| 数组 | O(n) | O(n) | O(n) | 按下标O(1)，插入删除需移动 |
| 链表 | O(n) | O(1) | O(1) | 已知节点位置时插入删除O(1) |
| 栈 | O(n) | O(1) | O(1) | 后进先出，只操作栈顶 |
| 队列 | O(n) | O(1) | O(1) | 先进先出 |
| 哈希表 | O(1) | O(1) | O(1) | 平均O(1)，最坏O(n)（哈希冲突） |
| 二叉搜索树 | O(log n) | O(log n) | O(log n) | 平均，最坏O(n)（退化成链表） |
| 平衡树(AVL/红黑) | O(log n) | O(log n) | O(log n) | 严格平衡 |
| 堆 | O(n) | O(log n) | O(log n) | 找最值O(1) |
| 图(邻接表) | O(V+E) | O(1) | O(E) | V顶点数，E边数 |

### 2. 常见排序算法复杂度

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|------|------|------|------|------|--------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | O(k) | 稳定 |
| 桶排序 | O(n+k) | O(n+k) | O(n²) | O(n+k) | 稳定 |
| 基数排序 | O(n*k) | O(n*k) | O(n*k) | O(n+k) | 稳定 |

### 3. 复杂度分析实战

```python
# 示例1：两数之和（暴力法）
def two_sum(nums, target):
    for i in range(len(nums)):        # O(n)
        for j in range(i+1, len(nums)): # O(n)
            if nums[i] + nums[j] == target:
                return [i, j]
    return []
# 时间复杂度：O(n²)，空间复杂度：O(1)

# 示例2：两数之和（哈希表优化）
def two_sum(nums, target):
    seen = {}                           # O(n) 空间
    for i, num in enumerate(nums):     # O(n)
        if target - num in seen:       # O(1)
            return [seen[target-num], i]
        seen[num] = i
    return []
# 时间复杂度：O(n)，空间复杂度：O(n)
# 用空间换时间，从O(n²)优化到O(n)
```

```python
# 示例3：二分查找
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:                # 每次规模减半
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
# 时间复杂度：O(log n)，空间复杂度：O(1)
```

## 问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 分不清O(n)和O(n²) | 嵌套循环没数清楚 | 逐层分析，嵌套相乘，并列相加 |
| 递归复杂度算错 | 没画递归树 | 画递归树，节点数×每层复杂度 |
| 忽略常数项的影响 | 大O只看趋势，但常数大也会慢 | 工程上也要考虑常数，O(n)不一定比O(n²)快（n很小时） |
| 哈希表认为一定O(1) | 忽略了哈希冲突和rehash | 平均O(1)，最坏O(n)，设计好哈希函数和负载因子 |
| 排序算法选择困难 | 不了解各算法适用场景 | 数据量小用插入排序，通用用快排，要稳定用归并，整数用计数排序 |
| 空间复杂度算错 | 把输入空间也算进去了 | 只算额外空间，递归要算调用栈 |
| 平均和最坏搞混 | 没明确说明 | 通常说最坏，特殊情况要说明（如快排平均O(nlogn)最坏O(n²)） |

## 拓展

**学习路径**：
1. **基础**：大O表示法、常见复杂度等级 → 1天
2. **数据结构**：数组、链表、栈、队列、哈希表、树、堆、图 → 1周
3. **算法**：排序、查找、递归、分治、贪心、动态规划、回溯 → 2周
4. **进阶**：图算法、字符串匹配、随机算法、近似算法 → 持续

**面试常考复杂度**：
- 排序算法的时间/空间复杂度和稳定性（必考）
- 哈希表为什么平均O(1)
- 快速排序的最坏情况和优化
- 红黑树和AVL树的区别
- B树和B+树的区别（数据库索引）
- 图的DFS/BFS复杂度
- 动态规划的状态转移分析

**推荐资源**：
- 《算法导论》- 经典教材，理论深入
- 《数据结构与算法分析》- 适合入门
- LeetCode：刷题平台，按难度和标签分类
- 可视化：https://visualgo.net/ （算法可视化）
- B站：搜索"算法可视化"，直观理解

**对于全栈+AI方向的建议**：
- 不需要深入研究算法竞赛级别的内容
- 掌握基础数据结构和常见算法即可
- 重点理解复杂度分析，能评估代码效率
- 面试前刷 LeetCode Hot 100 题
- AI方向更看重工程能力和系统设计，算法是基础但不是核心
