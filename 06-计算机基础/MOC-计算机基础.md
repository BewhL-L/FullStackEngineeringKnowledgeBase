# 🧠 计算机基础 MOC

> 软件开发的底层根基：计算机网络、操作系统、数据库原理、数据结构与算法、设计模式与架构、安全与测试六大领域，共 80+ 篇文档，也是面试高频考点。
>
> **学习建议**：数据结构与算法是基础，计算机网络和操作系统是面试重点，数据库原理是后端必备，设计模式提升架构能力，安全与测试保障质量。

---

## 📚 学习路线

```text
入门阶段：计算机网络基础 → 操作系统概念 → 数据结构入门 → 算法基础
进阶阶段：HTTP/HTTPS深入 → 进程线程与内存管理 → 数据库索引与事务 → 常用算法
高级阶段：TCP/IP协议栈 → JVM调优 → 数据库性能优化 → 动态规划与图论
专家阶段：分布式系统 → 编译原理 → 架构设计 → 安全攻防
```

## 🔗 知识关联

```text
计算机基础体系
├── 计算机网络 ← 所有分布式系统的基础
│   ├── HTTP/HTTPS → Web开发、API设计
│   ├── TCP/IP → 网络编程、RPC框架
│   └── DNS/CDN → 高可用架构、性能优化
├── 操作系统 ← 程序运行的底层环境
│   ├── 进程/线程 → 并发编程、JUC
│   ├── 内存管理 → JVM内存模型、GC
│   └── IO模型 → NIO、Netty、Reactor
├── 数据库原理 ← 数据存储与查询
│   ├── 索引 → SQL优化、查询性能
│   ├── 事务 → 数据一致性、分布式事务
│   └── 分库分表 → 高并发、海量数据
├── 算法与数据结构 ← 编程的基本功
│   ├── 哈希表 → HashMap、缓存
│   ├── 树 → 数据库索引、文件系统
│   └── 动态规划 → 最优解问题、面试高频
├── 设计模式与架构 ← 软件设计的智慧
│   ├── 设计模式 → 代码复用、可维护性
│   ├── 架构原则 → 系统设计、可扩展性
│   └── 分布式 → 高可用、高并发、一致性
└── 安全与测试 ← 质量保障
    ├── 安全 → 数据保护、攻击防御
    └── 测试 → 质量保证、回归测试
```

- **JVM** 是 Java 程序的运行环境，与 [[MOC-后端开发|Java 技术栈]] 和 [[Java-并发编程JUC|并发编程]] 深度关联
- **计算机网络** 是所有分布式系统的基础，与 [[MOC-分布式与中间件|分布式系统]] 通信原理相关
- **数据库原理** 与 [[MOC-数据库与缓存|数据库与缓存]] 技术栈紧密关联
- **算法与数据结构** 是所有编程的基础，面试高频考点
- **设计模式** 提升代码质量和架构能力，与 [[MOC-后端开发|后端开发]] 架构设计相关
