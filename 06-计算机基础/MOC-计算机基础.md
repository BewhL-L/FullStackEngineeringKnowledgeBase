## 🔗 知识关联

```
Java 程序运行
   ↓
JVM（内存管理/GC/类加载）
   ↓ 依赖
操作系统（进程/线程/内存/IO）
   ↓ 通信
计算机网络（TCP/IP/HTTP）
```

- [[06-计算机基础/JVM 知识点系统梳理_优化版|JVM]] 是 Java 程序的运行环境，与 [[02-后端开发/Java知识点完整整合大全_优化版|Java 基础]] 和 [[02-后端开发/并发编程 知识点系统梳理_优化版|并发编程]] 深度关联
- [[06-计算机基础/计网OS八股 知识点系统梳理_优化版|计网 OS]] 是所有软件开发的底层基础，网络部分与 [[04-分布式与中间件/MOC-分布式与中间件|分布式系统]] 通信原理相关
- 面试准备：JVM + 计网 + OS 是后端面试的八股文核心，配合 [[02-后端开发/MOC-后端开发|后端开发]] 技术栈

3. **JVM**：[[06-计算机基础/JVM 知识点系统梳理_优化版|JVM 知识点梳理]] — 内存模型、GC、类加载
