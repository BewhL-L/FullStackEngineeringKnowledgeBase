# 数据结构与算法知识点系统梳理（优化版）

> **文档说明**：系统梳理数据结构与算法核心知识，涵盖线性表、树、图、哈希表、排序、查找、动态规划等面试高频考点。

---

## 1. 概述

数据结构是数据的组织方式，算法是解决问题的步骤。两者是计算机科学的基础，也是面试的核心考察内容。

**复杂度分析**：
- **时间复杂度**：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
- **空间复杂度**：算法所需额外空间

## 2. 线性表

### 2.1 数组（Array）

- 连续内存存储，支持随机访问 O(1)
- 插入删除 O(n)（需要移动元素）
- 适合读多写少场景

### 2.2 链表（Linked List）

| 类型 | 特点 |
|------|------|
| 单链表 | 每个节点指向下一个，只能从头遍历 |
| 双链表 | 每个节点指向前一个和后一个，可双向遍历 |
| 循环链表 | 尾节点指向头节点 |

- 插入删除 O(1)（已知节点位置）
- 查找 O(n)
- 适合写多读少场景

> 🔍 **知识点深度解析**
>
> **作用**：数组和链表是最基础的数据结构，理解它们是掌握其他结构的基础。
>
> **原理**：数组在内存中连续存储，通过 `首地址 + 下标 * 元素大小` 计算元素地址，所以随机访问 O(1)，但插入删除需要移动后续元素 O(n)。链表节点不连续，每个节点存数据和指针，插入删除只需修改指针 O(1)（已知位置），但查找需要遍历 O(n)。ArrayList 是动态数组（扩容时复制到新数组），LinkedList 是双链表实现。
>
> **用法要点**：① 已知下标频繁读用数组，频繁插入删除用链表；② 链表题常用虚拟头节点（dummy）简化边界处理；③ 快慢指针找中间节点/环；④ 面试常考：数组 vs 链表、链表反转、链表环检测、合并有序链表。

### 2.3 栈（Stack）

- 后进先出（LIFO）
- 操作：push、pop、peek 均 O(1)
- 应用：函数调用栈、括号匹配、表达式求值、撤销操作

### 2.4 队列（Queue）

- 先进先出（FIFO）
- 操作：enqueue、dequeue O(1)
- 应用：任务排队、BFS 广度优先搜索
- **双端队列（Deque）**：两端都可进出
- **优先队列（PriorityQueue）**：按优先级出队，底层堆实现

## 3. 树

### 3.1 二叉树

每个节点最多两个子节点（左、右）。

**遍历方式**：
```
前序：根 → 左 → 右
中序：左 → 根 → 右
后序：左 → 右 → 根
层序：按层从上到下、从左到右（BFS）
```

### 3.2 二叉搜索树（BST）

- 左子树所有节点 < 根 < 右子树所有节点
- 中序遍历结果有序
- 查找/插入/删除平均 O(log n)，最坏 O(n)（退化成链表）

### 3.3 平衡二叉树（AVL）

- 左右子树高度差不超过 1
- 插入删除通过旋转维持平衡
- 查找 O(log n)，但旋转开销大

### 3.4 红黑树

- 自平衡二叉搜索树，节点红/黑
- 规则：根黑、红节点子节点黑、任意路径黑节点数相同
- 最长路径 ≤ 2 × 最短路径
- 插入删除 O(log n)，比 AVL 旋转少
- **应用**：HashMap（JDK8+）、TreeMap、Linux 进程调度

> 🔍 **知识点深度解析**
>
> **作用**：树是面试重点，BST/红黑树/堆是高频考点。
>
> **原理**：BST 左小右大，中序遍历有序，但极端情况退化成链表（有序插入）。AVL 严格平衡（高度差≤1），查询快但插入删除旋转多。红黑树用颜色规则近似平衡，不严格高度差，插入删除最多 3 次旋转，综合性能好，工程中更常用（HashMap 链表长度>8 转红黑树）。堆是完全二叉树，大顶堆父≥子（堆顶最大），小顶堆父≤子，插入删除 O(log n)，取最值 O(1)。
>
> **用法要点**：① BST 中序遍历有序是解题关键；② 红黑树了解规则和应用，不需要手写；③ 堆适合 TopK 问题（小顶堆维护前K大）；④ 面试常考：树的遍历（递归+迭代）、BST 验证、红黑树特点、堆排序、最近公共祖先。

### 3.5 堆（Heap）

- 完全二叉树，数组存储
- 大顶堆：父节点 ≥ 子节点
- 小顶堆：父节点 ≤ 子节点
- 插入/删除 O(log n)，取最值 O(1)
- 应用：优先队列、堆排序、TopK 问题

## 4. 图

### 4.1 存储方式

- **邻接矩阵**：二维数组，适合稠密图
- **邻接表**：数组+链表，适合稀疏图

### 4.2 遍历

- **DFS（深度优先）**：栈/递归，一条路走到底
- **BFS（广度优先）**：队列，按层遍历，最短路径

### 4.3 最短路径

| 算法 | 适用场景 | 时间复杂度 |
|------|----------|------------|
| Dijkstra | 非负权单源最短 | O(E log V) |
| Bellman-Ford | 有负权单源 | O(VE) |
| Floyd-Warshall | 多源最短 | O(V³) |

### 4.4 最小生成树

- **Prim**：从顶点出发，适合稠密图
- **Kruskal**：从边出发，适合稀疏图（并查集）

## 5. 哈希表

- 键值对存储，平均查找/插入/删除 O(1)
- 哈希函数：key → 数组下标
- **哈希冲突解决**：
  - 链地址法（HashMap 用这个，链表+红黑树）
  - 开放寻址法（线性探测、二次探测）
- **负载因子**：元素数 / 数组长度，超过阈值扩容（HashMap 0.75）

> 🔍 **知识点深度解析**
>
> **作用**：哈希表是最常用的数据结构之一，HashMap 是面试必考点。
>
> **原理**：通过哈希函数将 key 映射到数组下标，实现 O(1) 访问。不同 key 可能映射到同一位置（哈希冲突），HashMap 用链地址法（数组+链表），JDK8 后链表长度>8 且数组长度≥64 时转红黑树。扩容时数组长度翻倍，重新计算所有元素位置（rehash）。负载因子 0.75 是空间和时间的折中。HashMap 非线程安全，ConcurrentHashMap 线程安全（CAS+synchronized）。
>
> **用法要点**：① 自定义对象作 key 必须重写 hashCode 和 equals；② 初始容量设为 2 的幂（HashMap 要求）；③ 面试常考：HashMap 原理、扩容机制、哈希冲突、JDK7 vs JDK8、ConcurrentHashMap 实现、红黑树转换条件。

## 6. 排序算法

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|----------|----------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数排序 | O(n+k) | O(n+k) | O(k) | 稳定 |
| 桶排序 | O(n+k) | O(n²) | O(n+k) | 稳定 |
| 基数排序 | O(n×k) | O(n×k) | O(n+k) | 稳定 |

> 🔍 **知识点深度解析**
>
> **作用**：排序算法是基础，快排/归并/堆排是面试重点。
>
> **原理**：快速排序选基准（pivot），将数组分为小于和大于基准两部分，递归排序，平均 O(n log n)，最坏（已排序）O(n²)，优化选基准（三数取中/随机）。归并排序分治：拆分到单个元素，再两两合并，稳定 O(n log n)，但需要额外空间。堆排序用大顶堆，每次取堆顶放末尾，O(n log n) 不稳定但空间 O(1)。TimSort（Java/Python 默认）是归并+插入的混合算法，实际数据性能好。
>
> **用法要点**：① 快排是最常用的内部排序；② 稳定性：相等元素排序后相对位置不变；③ 大数据量外部排序用归并；④ 面试常考：快排实现、快排 vs 归并、稳定性、各算法适用场景、TopK 用快排分区或堆。

## 7. 查找算法

- **顺序查找**：O(n)
- **二分查找**：O(log n)，要求有序
- **哈希查找**：O(1)
- **二叉搜索树**：O(log n) 平均

```java
// 二分查找模板
int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2; // 防溢出
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

## 8. 算法思想

### 8.1 动态规划（DP）

- 将问题分解为子问题，保存子问题结果避免重复计算
- 三要素：状态定义、状态转移方程、初始状态
- 典型题：斐波那契、爬楼梯、背包问题、最长公共子序列、最大子数组和

### 8.2 贪心算法

- 每步选局部最优，期望全局最优
- 需证明贪心正确性
- 典型题：活动选择、零钱兑换（特定面额）、区间调度

### 8.3 回溯算法

- 深度优先搜索 + 剪枝
- 典型题：全排列、子集、组合、N皇后、数独

### 8.4 分治算法

- 分解 → 解决 → 合并
- 典型题：归并排序、快速排序、二分查找

## 📝 精简总结

- 数组随机访问 O(1)，链表插入删除 O(1)，各有优劣
- 栈 LIFO、队列 FIFO，优先队列用堆实现
- BST 中序有序，红黑树近似平衡，HashMap 用链地址法
- 排序：快排平均最快，归并稳定，堆排空间 O(1)
- 查找：二分 O(log n)，哈希 O(1)
- 算法思想：DP（子问题+记忆）、贪心（局部最优）、回溯（DFS+剪枝）、分治（分解合并）
- 刷题路径：数组→链表→哈希→栈队列→树→动态规划→图
