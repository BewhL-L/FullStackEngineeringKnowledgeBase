# issue-v32-pawpage 全面评审 + 优化提示词

评审对象：`issue-v32-pawpage.html`（3796 行 / 423 KB 单文件）
参照：① 彩色胶布 + 便利贴点缀的模块装饰语言；② niwacan 的色块版式
风格定位（已确认）：波点艺术 · 可爱风

---

## 一、总体判断

**骨架合格，性格不足。** 工程完成度高（无外链、字体内联、键盘可达、aria 齐备），但作为"波点艺术 + 可爱风"的作品集，现在的页面更像一本**米色笔记本**，而不是一本**贴纸手账**。

三个结构性问题：

1. **颜色只做记号，不做容器。** 全站只有首屏那块黄绿色和证据区的薄荷绿是"面"，其余全是白纸 + 2px 细线 + 18px 小圆角。niwacan 的关键不是配色，是**色块本身当容器**，现在缺这一层。
2. **波点是背景噪点，不是视觉语言。** 页面底纹的波点极淡且只有一个密度，首屏黄绿块里的波点却密得多。同一种元素两种规格，看起来像两套设计。
3. **装饰是微量的、藏在边上的。** 胶布只有 1 种颜色、1 种位置，便利贴贴着屏幕边缘漂着，与内容没有咬合关系。

## 三、问题清单

### P0 — 直接削弱成品感

**1. 空置率 66%，页面在"呼吸"和"漏气"之间选错了**
全栈节内容到 y≈510 就结束了，节底在 ≈1500。证据节同样：薄荷块到 ≈525，其后 400px 空白。
根因：`.scene` 是 `position:fixed` 的固定书架场景，section 又给了过大的 `min-height` / padding，两者叠加产生整屏空白。
处理：`min-height` 改为 `auto`，节间距统一到 `clamp(88px,9vh,132px)`；书架场景改为只在**首屏与页脚**出现，中间滚动区不再固定铺底。

**2. 宠物图形是两个风格不同的剪影贴片**
腊肠犬是深棕实块、头身比约 1:1.2（真实体长比约 1:2.4），四条腿短到看不出结构，尾巴像一根铁丝，没有光源、没有接地阴影；三花猫是浅色平涂 + 一张白纸。两者与书架（平涂淡彩、有描边）不是一套语言。
这解释了"建模丑陋"的观感：**它根本不是 3D，是两张被塞进场景的剪影。**（详见第五节）

**3. 首屏左栏与便利贴打架**
`CHUNK 512` 便利贴贴在 `left:0` 附近，与 eyebrow 胶囊（全栈 / Agent / 检索）在同一视觉层叠压，读起来像渲染错误。

**4. 全站缺"色块容器"**
niwacan 的版式逻辑是：满色块 + 大圆角（36–44px）+ 无描边 + 内容直接坐在色块上。现在是：白纸 + 2px 描边 + 18px 圆角 + 硬投影。后者是"纸片"，前者是"舞台"。可爱风需要后者。

### P1 — 影响专业度

**5. 波点规格不统一**：首屏密（≈10px 间距）、页面底疏（≈34px 间距）、`taped::after` 又是第三套。应统一为三档密度并在 tokens 里定义。
**6. 高亮条压字**："真实系统。"下方的薄荷色长条与字形下缘重叠约 4px，且两端齐平，没有马克笔的手感。
**7. 五层列表的 02–05 对比度过低**：`--ink-3` 在 `#FFF7E9` 上只有 4.26:1，非激活项被读成禁用态。
**8. 检查器卡片右上角的大号衬线"01"被卡边裁切**，与 `INTERFACE / STREAM / 01` 标签挤在一起。
**9. 胶布只有一条轨道**：`right:38px` 固定，所有卡片胶布位置一模一样，失去"手工贴"的随机感。
**10. 侧边便利贴（CHUNK 512、k-60）与内容无关联**，在 1100px 以下会压到正文。

### P2 — 打磨项

**11.** 书架的底部被 `fixed` 场景裁切，页面滚动时永远只露出上半截。
**12.** `prefers-reduced-motion` 下 `.rv` 仍是 `opacity:0` 起手，靠 JS 兜底；JS 失效即白屏。
**13.** 单文件 423 KB，字体已内联为 base64（约 300 KB），首次打开在移动端有 0.8–1.2s 的解析阻塞。

## 四、与你给的两个参照差在哪

### 参照 ① 彩色胶布

它的有效点不在"贴了胶布"，而在三条纪律：

- **物理暗示**：胶布宽度 60–110px、长度 18–22px、倾角 -4°~+3°，半透明（.78–.9），边缘有撕裂或斜切——它是"把纸按住了"，不是装饰横条。
- **颜色服从分区**：胶布色 = 该模块的分区色，不引入第 7 种颜色。
- **密度克制**：每屏 2–3 条，多一条就廉价。

现在的问题：只有 lime 一种、只有一条固定轨道、没有撕裂边（用的是 `repeating-linear-gradient` 假装齿孔，放大后是规则条纹）。

### 参照 ② niwacan 版式

可直接迁移的四条：

1. **色块当容器**：一张卡片就是一整块颜色，圆角 36–44px，无描边，投影极浅。
2. **咬合**：图片块与色块错位叠压 12–20px，边缘圆角不同，形成"贴上去的"层次。
3. **图形化字标**：超大 logo 字压在插画上（ABOUT 竖排）；对应到你的页面，是把"罗子强"或"AI 应用工程"做成 200px 级的图形元素，而不是 16px 的导航文字。
4. **圆形贴纸破格**：PICK UP 圆章骑在两个色块的接缝上——这是最便宜也最提气的装置。

## 五、宠物图形：为什么丑，怎么修

**目前是平面剪影，不是任何形态的 3D。** 判据：无高光、无明暗交界、无环境反射、无接触阴影、无色温变化。加上造型比例错误（头过大、腿过短、尾巴无体积），所以观感是"贴纸被压扁"。

三条路线，按投入排序：

| 路线 | 做法 | 观感上限 | 工时 | 何时用 |
|---|---|---|---|---|
| **C 贴纸化（先做）** | 保留平面，但改成"带白边的圆形贴纸"：白描边 6px + 硬投影 + 轻微旋转，配一次性入场弹跳 | 可爱、成立，但仍是 2D | 半天 | 本周就要能看 |
| **B 2.5D 分层（再做）** | 切成 body / head / ear×2 / tail 五层，视差位移 6–14px + 呼吸 1.5% + 尾摆 | 有生命感 | 2–3 天 | 想让它"活" |
| **A 真 3D（目标）** | 三视图 → 建模 → glTF → three.js + IBL + 软阴影 | 照片级 | 3–5 周 | 首页镇场 |

关键提醒：**A 路线的前置条件是"去光的贴图"**，直接拿现在的平涂剪影去建模，做出来还是塑料玩具。具体资产要求见第六节 P4。

```
重构这个单页作品集的视觉系统，风格定位：波点艺术 + 可爱风（手账 / 贴纸语言）。
保持现有信息架构、文案、交互功能与可访问性不打折，只重做视觉层。

【颜色：把"标记色"升级为"容器色"】
- 底色纸：#FFF7E9；纸面卡：#FFFDF7。
- 墨色：#3D2B24（主体）、#5C463A（正文，替换现有的 #8A7264，保证 ≥4.5:1）。
- 分区色各给三档：50 浅底 / 400 主色 / 800 深字，用于"满色块容器"：

### P2 · 模块装饰系统（给代码助手）

```
为这个页面实现一套"手账贴纸"装饰系统，用 CSS 伪元素实现，不引入图片资源、不影响布局、不拦截点击（pointer-events:none）。

【1. 彩色胶布 tape】
- 规格：宽 64–112px（随容器宽度 clamp(64px,7vw,112px)），高 20–24px，圆角 1px。
- 倾角：-4° 到 +3°，同一页面内角度必须不同（用 nth-of-type 或 data 属性区分）。
- 质感：背景为分区色 400 档，opacity .82；叠加 repeating-linear-gradient(90deg, rgba(255,255,255,.22) 0 3px, transparent 3px 9px) 做出纵向纤维；边缘用 clip-path 做出 2–4px 的不规则撕裂口，不要用规则齿孔。
- 位置：只允许三种——卡片上沿居中偏右、图片与色块交界处、标签左上角。全屏 ≤3 条。
- 颜色必须等于该模块的分区色，不引入新色。

【2. 便利贴 note】
- 尺寸 96–132px 见方，背景取 50 档，1px 描边 #EAD8C0，纸面有一道极浅的对角折痕（linear-gradient 透明度 .05）。
- 默认 rotate(-2deg)，hover 时 translateY(-4px) rotate(0)，transition .22s。
- 内容限 2 行，字号 10–11px，字距 .06em，可含一个手写风的下划线。
- 必须锚定到内容：用 grid 放到对应模块的角上，禁止 position:fixed 漂在视口边缘。

【3. 撕纸边 torn edge】
- 用于区块之间的分隔：伪元素高 10px，背景与上一区块同色，clip-path 用 12–18 段随机折线。
- 每屏最多 1 处。

【4. 圆形贴纸章 */
- 直径 76–104px，白描边 6px，背景分区色 400，内部两行字（上方英文 9px 字距 .18em，下方中文 12px 800）。
- 骑在两块容器的接缝上（负 margin 24–32px），这是最容易出效果的装置，全站用 2 次。

【5. 打孔活页】
- 章节左栏加 3 个 8px 圆孔，纵向等距，孔内为底色，孔边 1px 阴影，暗示这一页是从活页夹里抽出来的。

【6. 马克笔高亮】
- 关键词高亮用两层：底层 14px 高的色条，两端各收 3px 不规则缺口（clip-path），与文字基线错位 4px；上层文字保持原色。
- 现有实现是高亮条与字重叠，需要改为 z-index:-1 且下移 2px。

【7. 票根撕线】
- 数据条两端做成半圆缺口 + 中间 2px 虚线，用于"9,521""79"这类数字条，暗示可撕下的存根。

【8. 印章】
- 一个 15° 倾斜的矩形章（描边 2px、内部无底色），用于"已验证 / VERIFIED"，压在数字块的右下角，opacity .55。

【约束】
- 装饰元素总数每屏 ≤3，超过即视为噪声。
- 全部装饰在 900px 以下断点隐藏或减半，避免与正文抢位。
- 所有装饰不得进入 tab 顺序，aria-hidden="true"。
```

### P4 · 3D 宠物（给建模 + 前端）

**资产要求（建模侧）**

```
按三视图重建这只长毛腊肠犬，产出可直接用于网页的 glTF 2.0 资产。

形状：
- 严格按三视图正交对齐，体长:肩高 ≈ 2.4:1，胸深大于腹深，腿短但骨骼清晰（肘、腕、跗关节可见）。
- 头部：吻部略长于头骨，额段清晰，耳根低于头顶线，耳片长至下颌。
- 尾巴：尾根粗、全长约为体长的 45%，自然下垂微弯。

拓扑与贴图：
- LOD0 ≤ 20k 三角面，四边面为主，关节处环形布线 ≥3 圈。
- 贴图：2048×2048，albedo 必须去光（不含任何阴影与高光），法线由灰度高度图生成，roughness 按分区给值（鼻子 .25 / 眼睛 .05 / 毛发 .70 / 耳内 .85 / 爪垫 .55）。
- 毛发出 hair cards：4–6 层，宽 24–48px，alpha 边缘要打散，禁止硬边矩形。

导出：
- .glb + meshopt 压缩 + KTX2 纹理；总包 ≤ 4 MB。
- 命名：Body / Head / Ear_L / Ear_R / Tail / Eye_L / Eye_R / Collar / Bell。
- 眼睛、项圈、铃铛必须独立网格。
```

**前端规格（代码侧）**

```
用 three.js 把这个角色接入页面，作为一个独立组件 <PetStage>。

场景与光照：
- PerspectiveCamera fov 35，初始为前 3/4 略高，orbit 限制水平 ±35°、垂直 -10°~25°。
- ACESFilmicToneMapping，exposure 1.0，outputColorSpace sRGB。
- 主光 DirectionalLight 5500K 强度 2.0，开阴影 PCFSoft，mapSize 2048。
- 环境：HDRI 经 PMREMGenerator 生成 scene.environment，强度 0.8（真实感的主要来源，不可省）。
- 地面只接收阴影：ShadowMaterial opacity .25；另加一层 blob 接触阴影贴片，紧贴脚下。

材质：
