## 第二部分 · 参照与原则（编辑设计 / 顶级作品集站的共同点）

参照对象类型：编辑型作品集与刊物式长页（Swiss 排版传统 + 现代编辑设计）。

1. **编辑优先**：页面读起来要像一本排过版的刊物，不是"模板库里灌了内容"。
2. **结构可见**：网格、细线、对齐、间距本身承担构图，不是装饰。
3. **克制强调**：一个主强调色，出现频率低；分区差异靠 tint 与数字，不靠换色。
4. **行宽纪律**：正文 45–75 字符/行；中文按 18–24 字/行（17px 字号下约 620–720px）。
5. **级差要狠**：标题与正文至少 4× 级差（112px 对 17px），中间档位少而清晰。
6. **非对称栅格**：12 列，正文 6 列 + 边注 2 列 + 右留白 4 列；拒绝居中排版。
7. **留白有节奏**：主分区垂直留白 ≥120px，章节之间比段落之间大一档。
8. **接近锐角**：卡片 8–14px，按钮 8–10px，标签 4–6px；不做"圆角一切"。
9. **细线墨色**：结构用 1px 墨线，层次用一档极轻投影，不做多层重阴影。
10. **插图只在一个位置发力**：角色/插画集中在一处，其余交给排版。

## 第三部分 · 提示词正文（整段复制）

```
你是资深编辑设计师 + 前端工程师。目标：把一个 AI 应用工程的作品集页面，
做成"一本排过版的刊物"，同时保留两只宠物作为叙事角色。

【硬约束】
1. 文案、分区顺序、检索台逻辑、证据数字，一个字都不改；只改版式、材质、动效、插画。
2. 单文件 HTML，字体与资源内联，不引 CDN；file:// 直接能开。
3. 所有动效只用 transform / opacity；prefers-reduced-motion 下全部静态化。
4. 交付前必须给出：几何实测（行宽/栅格/溢出）、逐帧动作状态、内容一致性比对。

【画布与栅格】
- 画布上限 1560px；页边 gut 用 clamp(32px, 5vw, 112px)，左右不对称：
  左页边多 8px（装订侧更宽），右页边少。
- 12 列栅格：栏间距 24px。正文占 6 列（620–720px 上限），边注 2 列，
  右侧留白 4 列。任何正文段落不得超过 22 个汉字/行。
- 分区垂直留白 128px，章节之间 176px；段落之间 24px，标题与正文 12px。
- 所有尺寸走 4px 模数：4 / 8 / 12 / 24 / 40 / 64 / 96 / 128 / 176。

【首屏 · 封面（重做）】
按封面阅读顺序排版，自上而下四层，每层都要有对应的排版标记：
1. 报头行：左侧 "PAW & PAGE · PORTFOLIO 2026"，右侧期号 "NO.03"，中间一条通栏 1px 墨线。
2. 书名：占据画面 45–55% 宽度，字号 clamp(56px, 7.4vw, 132px)，行高 0.94，字距 -0.026em。
   书名下方 24px 处一条 64px 短墨线。
3. 封面语：三行，放在右侧 4 列内，每行 = 序号（serif 13px/字距.14em）+ 标题（18px/800）+ 一句说明（12.5px）。
   行间用 1px 细线分隔，不用卡片、不用阴影、不用圆角。
4. 页脚条：左下 meta（地点/状态/无追踪），右下签名 "woof — 一起把答案找出来"，中间页码 "P.01"。
- 封面框：inset 16px 的 1px 细线，四角各一枚 9px 网点方块（不是圆点）。
- 左页边竖排小字（书脊），字距 .34em，10px，只在大屏出现。

【章节跨页（重做）】
每个分区是一张跨页，左页是章节页，右页是正文页：
- 左页（宽 220px）：页码（serif clamp(48,4.4vw,72)）、章名（10px/字距.2em/大写）、
  一句副题（11px/行高1.6）、一条 2px 强调色短竖线（只在页码上方 56px）。
- 右页：正文列从 64px 处开始；正文页左边缘有一条 1px 装订线 + 一列 12px 的刻度点（每 32px 一枚）。
- 每张跨页底部左侧 folio（serif 12px / "P.07"），右侧一枚 24px 章节色网点方块。
- 章节缝：一枚 9px 菱形 + 两侧各 40px 细线；不要爪印、不要贴纸。

【字级系统（只允许这七档）】
display 132 / 90 / h2 60 / h3 24 / body 17 / meta 13 / micro 11
- 中文正文 17px / 行高 1.75 / 颜色用 --ink-2（对比度 ≥ 7:1）。
- 数字一律 tabular-nums；大数字只用 serif 400，单位用 11px 大写。
- 标题 text-wrap: balance；正文 text-wrap: pretty。

【色彩】
- 主强调只有一个：琥珀 #E49A2E。出现位置：书名下划线、页码短线、folio 方块、主按钮、选中态。
- 分区色只做 tint（12% 透明度）与数字色，不做整块背景；禁止在同一屏出现两种满强度分区色。
- 纸：#FBF6EA；卡：#FFFDF8；墨：#1F1A16；弱化：#736759；细线：#E3D4BD。夜版不做。

【波点艺术（这次要有图形语言）】
不做满屏纹理。三处，各有明确作用：
1. 页边网点云：左页边蜜色 21px 网点、右页边薄荷 23px 网点，各用径向遮罩收到 42%/34% 不透明度。
2. 章节页眉：每个 h2 左上方一条 56×6px 的网点带（11px 间距），用分区色，不透明度 .75。
3. 角色驻地：两只宠物脚下的"网点地面"——一条 24px 高的网点渐隐带，密度随离角色距离衰减。
另外允许一个"波点图形"：一串 5 枚逐渐缩小的圆点，作为章节之间的连接符（不是装饰，是版式标点）。

【模块清单（统一三档圆角 + 一档阴影）】
- 纸卡（surf / trace / lab）：圆角 14、1px 墨线、阴影 5px 6px 0 rgba(31,26,22,.13) + 一条 1px 内高光；
  顶边左端 46×3px 强调色套准标记；右上角 8px 网点角块（不透明度 .35）。
- 索引卡（检索台）：横格线 28px 步进、左侧 1px 强调色书脊、圆角 14。
- 小控件（ch / step / arch-row）：圆角 12、1px 细线、无阴影；hover 只变边框与底色；选中 2px 强调色左线。
- 按钮：圆角 10；主按钮实心墨底奶油字；次按钮 1px 描边；按下 scale(.985)。
- 标签（kicker）：10.5px / 字距 .2em / 大写 / 前置 16×1.5px 强调色短线。
- 图标：一套线条图标（1.5px stroke，随字重变 2px），只用 outline，选中才 fill。禁止混用手绘散点。

【动效】
- 唯一缓动 cubic-bezier(.16,1,.3,1)；时长三档：160 / 300 / 520ms。
- 入场：元素 520ms 上移 14px + 淡入，同级 60ms 级联；只做一次。
- 章节转场：进入分区时，左页页码先出现（+80ms），正文列随后（+160ms），
  强调短线用 240ms 从 0 拉到 56px（transform: scaleY）。
- 交互动效只允许：边框色、底色、translateY(-2px)、scale(.985)。禁止 width/height/top/left 动画。
- 页面滚动保留现有的缓动运镜（easeInOutCubic，380–1000ms，随距离）。

【两只宠物（动作与状态机）】
角色：团子（三花猫，负责"挑"）、面条（长毛腊肠犬，负责"找"）。
动作共 8 套，按触发条件排队执行，不互相打断：
1. fetch —— 普通检索（命中 1–2 条）：狗冲刺到书架、翻架、叼回带真实书名的书，猫过来拍板。
2. duo —— 命中 ≥3 条：分头找，狗左架、猫右架，中线会合"取交集"。
3. eval —— 查询含"评测/指标/eval/MRR/Hit@"：两本并排对读，猫提醒"只看一个数会归错因"。
4. cache —— 同一句再提交：狗直接抽出缓存卡，说"这句问过了"，猫接"不用再跑全链路"。
5. fallback —— 0 命中：向量通道离线标记闪烁，狗塌肩垂耳"降级到关键词"，猫"先保证有答案"。
6. retry —— 覆盖率 <45%：书掉地、捡起、第二遍拿到。
7. cite —— 点来源：猫牵一根虚线回原文。
8. 通道动作 —— VECTOR 嗅、BM25 逐脊核对、GRAPH 顺关系线、RRF 叠三本。
状态机要求：
- 姿态类（is-walk/is-sit/is-sleep/is-sniff/is-alert/is-happy）与动作类（act-*）分离；
  pose() 不得清除气泡（talk）与舞台（stage）这类瞬态类。
- 每段动作有 token 守卫 + 全局节拍表，新动作开始时统一清空旧节拍。
- 已在目的地的角色仍要等 300ms 再回调，保证台词被读完。
- 同一时间只允许一只宠物处于 act-*；另一只做反应动作（抬头/看/坐）。
- 演出时把宠物临时提到前景（body.stage），12s 安全超时后退回背景。

【3D 资产接入（可选，按 A方案 A4 规格）】
- 已有 assets3d/Tuanzi.glb（732KB / 17,252 tris / 17 bones / 4 actions）与 Noodle.glb（781KB / 18,988 tris）。
- 用本地 vendor/three.min.js，不引 CDN；GLTFLoader 也放 vendor/。
- 材质用 MeshPhysicalMaterial：毛发 sheen .6 / sheenRoughness .7；眼睛独立网格 clearcoat 1.0 / roughness .05。
- 动画：Idle 循环（呼吸 1.2s、耳延迟 120ms、尾摆 3.5s 相位滞后 200ms、每 4–7s 眨眼 120ms）。
- Camera fov 35，初始 3/4 略高；orbit 水平 ±35°、垂直 -10°~25°。
- 降级：WebGL 不可用 → 静态 PNG（同构图同阴影）；60 帧低于目标 80% → 关阴影 + LOD1。
- 页面首屏不加载 3D；只在"角色驻地"分区加载，IntersectionObserver 进入时再拉资源。

【可访问性与性能】
- 正文对比度 ≥ 7:1，弱化文字 ≥ 4.5:1；焦点环 2px 强调色 + offset 3px。
- 所有交互元素命中区 ≥ 44px；宠物热区不覆盖任何正文链接。
- 首屏 3 秒出第一帧；滚动帧率桌面 60 / 移动 30。
- 不新增第三方脚本；不新增网络请求（3D 除外，且为同目录文件）。

【禁止项（出现即返工）】
- 渐变背景、玻璃拟态、彩色左条卡片、图标排排坐的三栏特性格、居中堆叠首屏。
- 用 emoji 当图标；用圆角矩形代替层级；用满屏纹理代替版式。
- 同一屏出现两种满强度强调色；阴影超过两档；圆角超过三档。
- 任意改变文案、分区顺序、检索逻辑与数字。

【验收清单（做完逐条勾）】
[ ] 正文行宽 ≤ 22 汉字，实测并给出数值
[ ] 首屏四层结构齐备（报头/书名/封面语/页脚条），有期号与 folio
[ ] 每张跨页都有左页章节页 + 右页装订线 + folio + 章节网点
[ ] 圆角只有 14/12/10 三档，阴影只有一档 + 内高光
[ ] 强调色同屏只出现一种满强度
[ ] 波点只出现在页边、章节页眉、角色地面三处，正文区干净
[ ] 8 套动作各有触发条件，逐条跑通并给出 className 快照
[ ] 同一句重复提交 → cache，0 命中 → fallback，两者文案不同
[ ] 内容比对：main/nav/dialog/mail/foot 与旧版逐字一致
[ ] 1440 / 1024 / 390 三档无横向溢出，宠物不盖正文
[ ] prefers-reduced-motion 下无循环动画
```
