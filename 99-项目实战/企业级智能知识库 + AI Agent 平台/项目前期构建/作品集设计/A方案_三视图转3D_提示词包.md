# 三视图 → 实时 3D（A 方案）提示词包

适用对象：长毛腊肠犬（黑棕 / 红毛）、三花猫、幼年金毛。
使用顺序按 A0 → A1 → A2 → A3 → A4，前两步不完成，后面全部无效。

---

## A0 · 补全建模所需的角度参考图

三视图只有正交三面，建模会缺 3/4 侧面、臀部、头顶、腹底四个盲区。
用现有三视图作为唯一身份参考，逐个角度派生。**关键：这四张必须是平光**，不要画家式明暗，否则建模时读不到形体。

### A0-1 前 3/4（左前方 45°）

```
以这张三视图为唯一的身份参考，生成同一个体的左前方 45° 视角全身图。

要求：
1）同一只动物、同一套毛色与花纹分布、同一项圈与铃铛、同一表情，不许改设定。
2）四足自然站立（不是坐姿），重心平均，头略转向镜头。
3）平光照明：均匀柔和的正面光，不产生明显明暗交界、不产生地面投影、不产生高光热点；整体亮度均匀，像建模用的转面参考。
4）纯白或浅灰纯色背景，无纹理、无网格、无标签、无文字。
5）构图：全身完整入画，四足与尾尖不切边，主体占画面高度约 80%。
6）画风与参考图一致，但笔触收敛、边缘干净，方便读取结构。

负面：不要坐姿、不要夸张透视、不要强投影、不要渐变背景、不要文字、不要多个个体。
```

### A0-2 后 3/4（右后方 45°）

```
以这张三视图为唯一的身份参考，生成同一个体的右后方 45° 视角全身图，用于建模参考。

要求：
1）同一只动物、同一毛色花纹、同一项圈，不许改设定。
2）四足自然站立，背对镜头略偏右，能看到臀部、后腿折叠关系、尾根位置与尾巴全长。
3）平光照明，无明暗交界、无投影、无高光热点。
4）纯白或浅灰纯色背景，无文字无标签。
5）全身完整入画。

负面：不要坐姿、不要尾部被身体遮挡、不要强投影、不要文字。
```

### A0-3 顶视

```
以这张三视图为唯一的身份参考，生成同一个体的正上方俯视全身图，用于建模时校核耳位、头顶花纹走向与身体宽度。

要求：
1）正俯视 90°，能看到头顶、耳根间距、背部花纹完整分布、四足伸出的位置、尾巴走向。
2）平光照明，无投影、无高光。
3）纯白纯色背景，无文字无标签。
4）全身完整入画，头在上尾在下。

负面：不要斜俯视、不要透视变形、不要文字。
```

### A0-4 腹底仰视（可选，做四足支撑与爪底时需要）

```
以这张三视图为唯一的身份参考，生成同一个体的仰视全身图，用于确认腹部毛色分界、四肢与爪底形态。

要求：
1）正仰视，四足自然展开，能看到胸腹交界、腹部毛色、爪底与肉垫颜色。
2）平光照明，无投影。
3）纯白纯色背景，无文字无标签。

负面：不要斜角、不要文字。
```

## A1 · 去光重绘 albedo（贴图底图）

水彩稿的暗部混着主观笔触，直接贴图会变成"彩绘模型"。必须重绘一张只带固有色、不带光影的贴图底图。

```
把这幅角色图重绘为纯 albedo 贴图：只保留固有色与花纹边界，去掉画面里所有光照信息。

必须去掉：
所有明暗渐变、投影、高光、反光、环境色、纸张纹理、笔触颗粒、线稿轮廓。

必须保留：
每一块花纹的准确形状与边界位置、各部分固有色、耳内/鼻头/爪垫/眼白的独立色块。

输出要求：
1）均匀平涂，同一色块内部零渐变、零噪点。
2）色块边界清晰但不描边，边界处不要抗锯齿过渡带。
3）整体明度略高于实物中间调（为后续光照留出余量）。
4）正交视角、无透视，与参考图构图一致。
5）背景纯中性灰 #808080，用于抠图。

负面：不要阴影、不要高光、不要渐变、不要纸纹、不要线稿、不要文字、不要网格。
```

### 附属：色板核对图

```
从上一张 albedo 中提取主色，输出一张色板图：横向排列 8–10 个等大色块，每块下方标注十六进制色值。
色块顺序按面积从大到小。不要其他元素、不要标题、不要装饰。
```

## A2 · 法线 / 粗糙度

重要提醒：图像模型直接"画"法线贴图不可靠，RGB 向量常错。推荐做法是**先生成灰度高度图，再在 Blender / Substance 里转法线**。下面是高度图提示词，不是法线贴图。

### A2-1 毛发走向高度图

```
把这幅角色图转成灰度高度图，用于生成法线贴图。

规则：
1）灰度代表高度：毛束凸起处偏白、毛束之间的沟槽偏黑，中值为 #808080。
2）沿每一束毛的真实生长方向拉出连续的细长凸起，长度 15–40 像素，宽度 3–6 像素，不要规则排列。
3）头部、耳缘、胸前、前腿后侧、尾巴的毛流方向必须符合该部位真实生长方向。
4）眼睛、鼻头、爪垫等光滑部位保持中灰或略亮，不要加毛流。
5）不要出现色相，只输出灰度；不要有大的明暗渐变（那是形体，不是表面细节）。

负面：不要彩色、不要整体明暗、不要描边、不要文字。
```

## A3 · 若用 AI 三维生成工具（Tripo / Rodin / 混元 3D）

这类工具吃的是单张图，提示词只需要管住"姿势与完整性"，其余靠图。

```
a single long-haired dachshund, standing on all four legs, full body visible, neutral calm pose,
head facing forward, tail extended and not overlapping the body, plain light grey background,
even flat lighting, no shadow, no props, no text, centered, whole animal inside frame
```

要点：**站立、全身、尾不遮体、平光、纯背景**。坐姿和趴姿会让 AI 补出的背面全错。

## A4 · three.js 实现规格（交给代码助手）

这是整条链路里最长也最关键的一条。复制整段使用。

```
用 three.js 实现一个可交互的角色展示组件，以下是完整规格。

【场景】
- 单一 WebGLRenderer，antialias 开启，outputColorSpace 用 SRGB，toneMapping 用 ACESFilmic，exposure 约 1.0。
- 相机：PerspectiveCamera，fov 35，初始位姿为前方 3/4 略高视角，orbit 限制为水平 ±35°、垂直 -10°~25°，禁止穿到地面以下。
- 背景：透明或与页面同色的纯色，不要渐变、不要贴图。

【光照】
- 主光：一盏 DirectionalLight，色温约 5500K，强度 2.0，开启阴影，shadow.mapSize 2048，使用 PCFSoftShadowMap。
- 环境：用一张 HDRI 跑 PMREMGenerator 作为 scene.environment，环境强度 0.8（这是真实感的主要来源，不要省）。
- 补光：一盏低强度 HemisphereLight，天光偏冷、地光偏暖，强度 0.35。
- 地面：接收阴影的 ShadowMaterial 平面，透明度 0.25，不使用实体地板。
- 不开启 SSAO / Bloom 等后处理，除非帧率有余量。

【模型】
- 格式 glTF 2.0（.glb），几何用 meshopt 压缩，纹理用 KTX2/Basis。
- 网格命名规范：Body / Head / Ear_L / Ear_R / Tail / Eye_L / Eye_R / Collar / Bell。
- 眼睛必须是独立网格并单独使用一层高光材质（clearcoat 1.0，roughness 0.05）。
- 材质使用 MeshPhysicalMaterial：毛发起用 sheen 0.6、sheenRoughness 0.7、sheenColor 略浅于 albedo；毛发 alpha 卡片用 alphaTest 0.5 + depthWrite true，避免排序问题。
- 所有纹理开启 anisotropy = renderer.capabilities.getMaxAnisotropy()。

【动画】
- 呼吸：胸腔骨骼纵向缩放 1.5%，周期 1.2 秒，使用 sin 缓动，循环。
- 耳朵：跟随呼吸延迟 120ms，幅度为胸腔的 60%。
- 尾巴：低频摆动，周期 3.5 秒，幅度 ±6°，相位比身体滞后 200ms。
- 眨眼：每 4–7 秒随机一次，时长 120ms，直接缩放眼皮或用 blend shape。
- 待机时轻微重心偏移：整体 root 横向位移 ±2px 等效，周期 8 秒。
- 所有动画用 requestAnimationFrame 统一驱动，禁止 CSS 动画与 WebGL 动画混用时间源。

【交互】
- 鼠标/触摸拖动旋转，松开后带惯性衰减回到初始角度的 30% 偏移处。
- 指针悬停时角色头部朝指针方向微转（±12° 上限），离开后 400ms 内回正。
- prefers-reduced-motion 为 reduce 时，关闭全部循环动画，只保留静态渲染。

【性能与降级】
- LOD0 ≤ 20k 三角面；首屏资源总量（glb + 贴图）≤ 4 MB。
- 桌面目标 60fps，移动 30fps；连续 60 帧低于目标 80% 时，关闭阴影并降到 LOD1。
- 设备像素比上限 2。
- 纹理按需加载：先加载 1K 版本渲染，后台替换为 2K。
- WebGL 不可用或加载失败时，回退为一张静态 PNG，并保持相同构图与阴影。

【可访问性】
- canvas 加 role="img" 与 aria-label 描述该动物外观。
- 不依赖颜色传达状态。
- 键盘可用 Tab 聚焦，方向键旋转，Esc 复位。

【验收标准】
1. 首屏 3 秒内在普通笔记本上出第一帧。
2. 角色脚下有紧贴的软阴影，视觉上"站得住"。
3. 停止交互后，能明显看出呼吸与尾巴的细微运动，但不产生机械感。
4. 移动端不出现掉帧卡顿与纹理闪烁。
5. 控制台无 WebGL 警告与纹理尺寸报错。
```

## 验收清单（做完对着勾）

- [ ] A0 四张角度图是平光，没有画家式明暗
- [ ] A1 albedo 里绝对看不到阴影与笔触，同色块内部零渐变
- [ ] 花纹边界位置与三视图逐块对得上，没有糊成一片
- [ ] A2 高度图的毛流方向符合该部位真实生长方向
- [ ] 站立姿势而非坐姿（AI 三维工具尤其容易错）
- [ ] roughness 分区表已落实到材质，不是全模型一个值
- [ ] 眼睛是独立网格且有单独高光层
- [ ] 阴影是紧贴的软阴影，不是悬浮的硬影
- [ ] 呼吸、耳延迟、尾摆三者相位不同，不同步
- [ ] 移动端有降级路径，且回退图与 3D 构图一致
