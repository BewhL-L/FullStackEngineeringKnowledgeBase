# 本地启动指南（新手友好版）

手把手教你把项目在本地跑起来。

---

## 一、准备环境

### 1. 安装 Python
- 安装 **Python 3.11**：https://www.python.org/downloads/
  （与 Docker 镜像、CI 一致。3.13 未验证全量依赖：`jieba` 能装，但 `chromadb` 一系不保证）
- 安装时勾选 **Add Python to PATH**
- 验证：命令行输入 `python --version`

### 2. 安装 Node.js
- 安装 Node.js 20 LTS：https://nodejs.org/
- 验证：`node -v` 和 `npm -v`

### 3. 获取大模型 API Key
- 用豆包（火山方舟）/ 通义千问 / DeepSeek 等任意 OpenAI 兼容接口
- 拿到：API Key、接口地址（Base URL）、对话模型名、向量模型名

---

## 二、启动后端

```bash
# 1. 进入后端目录
cd backend

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows（PowerShell）
venv\Scripts\Activate.ps1
# 如遇权限问题，先执行：
# Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
# Mac/Linux
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 配置环境变量
# Windows
copy .env.example .env
# Mac/Linux
cp .env.example .env
```

用编辑器打开 `backend/.env`，填入：
```ini
LLM_API_KEY=你的key
LLM_BASE_URL=你的接口地址
LLM_MODEL=你的对话模型
EMBEDDING_MODEL=你的向量模型
SECRET_KEY=随便一串字符（本地开发无所谓）
```

`.env.example` 默认是本机友好的 SQLite + Chroma，直接复制即可用。

```bash
# 6. 初始化数据库（AUTO_CREATE_TABLES=false，必须先跑这个）
python scripts/db_bootstrap.py

# 7. 启动
uvicorn app.main:app --reload --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功。
`db_bootstrap.py` 会自动判断：空库建全 / 老库 stamp / 已纳管升级，可重复执行。

打开浏览器访问 http://localhost:8000/docs 可以看到接口文档。

---

## 三、启动前端

**另开一个命令行窗口**（后端不要关）：

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖（首次较慢）
npm install

# 3. 启动
npm run dev
```

看到 `Local: http://localhost:5173/` 即成功，浏览器打开该地址。

---

## 四、完整使用流程

1. 打开 http://localhost:5173
2. 注册一个账号（任意用户名密码，密码 6 位以上）
3. 进入「知识库管理」→ 新建知识库
4. 点进知识库 → 上传一个 PDF/Word/TXT 文档
5. 等待状态从「处理中」变成「已完成」
6. 进入「智能问答」→ 选择知识库 → 提问
7. 进入「AI Agent」→ 试试问"现在几点"或"帮我算个账"

## 五、常见问题

### pip install 很慢
换国内源：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### npm install 很慢
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 上传文档后状态一直"处理中"
- 查看后端命令行报错
- 多半是 `EMBEDDING_MODEL` 或 API Key 配错了
- 向量模型和对话模型是两个不同的模型，确认都填对

### 问答时报错
- 检查 `LLM_API_KEY`、`LLM_MODEL`、`LLM_BASE_URL`
- 看后端日志具体错误

### 端口被占用
- 后端：`uvicorn app.main:app --reload --port 8001`
- 前端：修改 `vite.config.ts` 的 port，或关掉占用程序

### 前端连不上后端
- 确认后端在 8000 端口运行
- `vite.config.ts` 已配置代理，不要直接改前端请求地址
