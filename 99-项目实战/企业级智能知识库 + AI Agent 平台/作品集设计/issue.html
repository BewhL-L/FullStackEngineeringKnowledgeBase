03 / Evaluation
四个评测指标与归因层
指标看什么归因层
Hit@K正确文档有没有进前 K；golden QA 标注来源，按 K 计命中召回
MRR正确文档排得够不够前；取排名倒数平均排序
Context P/R拼进 Prompt 的资料干不干净；逐条按相关性标注上下文
LLM Judge是否只由资料支撑、是否答到点；强模型逐条打分生成

指标已实现 · 无可复现跑分 · 本页不报数。

04 / Field Notes

最危险的不是报错，是静默降级

BM25 缺 jieba 会降级成单字 + bigram——不崩，也不提示，只是中文检索悄悄变差。启动时打一行日志。

Prompt 注入不是“加个过滤器”

资料边界包裹 + 启发式检测；危险工具走 AST 白名单。每次调用前都问一遍。

评测的价值是归因，不是排名

检索差、排序差、上下文脏、生成胡说是四种病。四指标并看，才知道改哪一层。
