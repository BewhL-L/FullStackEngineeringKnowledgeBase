# 数据库设计文档模板

## 一、概述
标准化数据库设计文档，记录表结构、索引、关系、约束，是数据库维护和团队协作的基础。

## 二、模板结构
```markdown
# 数据库设计文档：[项目名]

## 1. 概述
- 数据库类型：MySQL 8.0 / PostgreSQL 15
- 字符集：utf8mb4
- 命名规范：表名小写下划线，字段名小写下划线

## 2. ER图
（使用Mermaid/PlantUML绘制实体关系图）

## 3. 表设计
### 3.1 [表名]
- 说明：[业务含义]
- 字段：
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| created_at | DATETIME | NOT NULL | 创建时间 |
- 索引：
| 索引名 | 字段 | 类型 | 说明 |
- 关系：[关联表] [关联字段] [1:N]

## 4. 数据字典
## 5. 变更记录
```

## 三、实操示例
设计原则：三范式规范化、必要时反范式优化、每张表有created_at/updated_at、软删除用deleted_at、索引覆盖高频查询。

## 四、常见问题与排查
- 表结构变更无记录 → 迁移脚本+版本管理（Flyway/Liquibase/Alembic）
- 缺少索引 → 基于查询模式设计，EXPLAIN验证
- 字段含义不明 → 注释+数据字典

## 五、进阶与最佳实践
- 从ER图生成DDL（dbdiagram.io）
- 版本化迁移：Alembic/Flyway
- 数据字典自动生成
- 分库分表规划：预估数据量
- 审计字段：created_by/updated_by
