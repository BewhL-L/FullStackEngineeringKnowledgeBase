### 2. tcpdump 命令

TCP（Transmission Control Protocol，传输控制协议）是一种面向连接的、可靠的传输层协议，通过三次握手建立连接、四次挥手断开连接，提供数据有序、无差错、不丢失的传输保证。

**核心要点**：
- 三次握手：SYN → SYN+ACK → ACK，建立可靠连接
- 四次挥手：FIN → ACK → FIN → ACK，优雅断开连接
- 滑动窗口：流量控制，接收方告知发送方可接收的数据量
- 拥塞控制：慢启动、拥塞避免、快重传、快恢复
- 可靠传输：序号、确认号、超时重传机制

**代码示例**：
# TCP 三次握手（伪代码）
# 客户端 → 服务端: SYN, seq=x
# 服务端 → 客户端: SYN+ACK, seq=y, ack=x+1
# 客户端 → 服务端: ACK, ack=y+1
# 连接建立完成

# Python TCP 服务端
import socket
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('0.0.0.0', 8080))
server.listen(5)
conn, addr = server.accept()
data = conn.recv(1024)
conn.send(b'Hello')
conn.close()

**常见问题**：
Q: 为什么连接建立需要三次握手而不是两次？
A: 两次握手无法确认客户端的接收能力，可能导致服务端资源浪费（已失效的连接请求）。三次握手确保双方收发能力都正常。
