# 浏览器开发者工具进阶

> **文档说明**：系统讲解 Chrome/Edge DevTools 的进阶用法，涵盖 Elements、Console、Sources、Network、Performance、Application、Lighthouse 等核心面板，以及断点调试、性能分析、远程调试、快捷键等高级技巧。
>
> **适用人群**：前端开发者、全栈开发者、需要调试 Web 应用的开发者
>
> **前置知识**：[[前端性能优化实战]]、[[Vue3-组合式API设计模式]]、[[Axios网络请求封装]]

## 一、概述

### 1. DevTools 面板总览

| 面板 | 快捷键 | 用途 |
|------|--------|------|
| **Elements** | `Ctrl+1` | DOM 结构、CSS 样式、布局调试 |
| **Console** | `Ctrl+2` | 日志输出、命令执行、错误查看 |
| **Sources** | `Ctrl+3` | 源码调试、断点、工作区 |
| **Network** | `Ctrl+4` | 网络请求分析、性能监控 |
| **Performance** | `Ctrl+5` | 运行时性能分析 |
| **Memory** | - | 内存分析、泄漏检测 |
| **Application** | - | 存储、缓存、Service Worker、PWA |
| **Security** | - | 安全信息、证书、混合内容 |
| **Lighthouse** | - | 综合审计（性能、可访问性、SEO） |
| **Recorder** | - | 用户流程录制与回放 |

> 打开 DevTools：`F12` 或 `Ctrl+Shift+I`（Mac: `Cmd+Opt+I`）

### 2. 命令菜单（Command Menu）

```text
Ctrl+Shift+P  打开命令菜单（类似 VS Code 的 Ctrl+Shift+P）

常用命令：
- > screenshot          截图
- > theme               切换主题
- > dock                切换停靠位置
- > disable cache       禁用缓存
- > emulate             模拟设备
- > clear               清除控制台
- > coverage            代码覆盖率
```

## 二、Elements 面板

### 1. DOM 操作

```text
DOM 调试技巧：
- 右键元素 → Break on → subtree modifications / attribute modifications / node removal
  （DOM 断点，元素变化时暂停）
- H 键：隐藏/显示选中元素
- Delete 键：删除选中元素
- 拖拽元素：调整 DOM 顺序
- 双击属性：编辑属性
- 右键 → Copy → Copy selector / Copy JS path / Copy XPath
```

### 2. CSS 调试

```text
样式面板技巧：
- 点击颜色块：取色器（可切换 HEX/RGB/HSL）
- 点击阴影：可视化阴影编辑器
- 点击 cubic-bezier：贝塞尔曲线编辑器
- :hov 按钮：强制元素状态（:hover/:active/:focus/:visited）
- .cls 按钮：添加/移除 class
- + 按钮：添加新规则
- 按住 Alt 点击颜色：切换格式

布局面板（Layout）：
- Grid 高亮：显示 CSS Grid 网格线
- Flexbox 高亮：显示 Flex 布局
- 层叠上下文：查看 z-index 层叠
```

### 3. 计算样式与盒模型

```text
Computed 标签：
- 查看最终计算后的样式
- 搜索属性
- 展开查看继承来源

盒模型可视化：
- 元素的 margin/border/padding/content 尺寸
- 鼠标悬停查看各部分数值
```

## 三、Console 面板

### 1. 控制台 API

```javascript
// 基础日志
console.log('普通日志')
console.info('信息')
console.warn('警告')
console.error('错误')
console.debug('调试')

// 格式化输出
console.log('用户: %s, 年龄: %d', '张三', 25)  // %s 字符串, %d 数字, %o 对象
console.log('%c 彩色文字', 'color: red; font-size: 20px;')  // CSS 样式

// 分组
console.group('用户信息')
console.log('姓名: 张三')
console.log('年龄: 25')
console.groupEnd()

// 表格输出
console.table([{name: '张三', age: 25}, {name: '李四', age: 30}])

// 计时
console.time('循环耗时')
for (let i = 0; i < 1000000; i++) {}
console.timeEnd('循环耗时')

// 计数
console.count('点击次数')
console.countReset('点击次数')

// 断言
console.assert(1 === 2, '1 不等于 2')  // 条件为 false 时输出

// 追踪调用栈
console.trace('函数调用追踪')

// 清空
console.clear()
```

### 2. 控制台实用函数

```javascript
// 选择元素（类似 jQuery）
$('selector')           // querySelector
$$('selector')          // querySelectorAll（返回数组）
$x('//xpath')           // XPath 选择

// 最近选中的元素
$0  // Elements 面板中最近选中的元素
$1  // 上一个选中的元素
$2, $3, $4, $5

// 事件监听
getEventListeners(element)  // 获取元素的事件监听器
monitorEvents(element, ['click', 'hover'])  // 监控事件
unmonitorEvents(element)

// 函数监控
monitor(fn)       // 函数调用时打印
unmonitor(fn)

// 其他
copy(object)      // 复制对象到剪贴板
inspect(object)   // 在 Elements 中定位元素
keys(object)      // Object.keys
values(object)    // Object.values
dir(element)      // 显示元素的 JS 属性（而非 DOM）
```

### 3. 实时表达式（Live Expression）

```text
点击眼睛图标 → 输入表达式 → 实时显示值
适用场景：
- 监控变量变化
- 监控 document.title
- 监控 window.scrollY
- 监控 performance.memory
```

## 四、Sources 面板

### 1. 断点类型

| 断点类型 | 说明 | 设置方式 |
|---------|------|---------|
| **行断点** | 执行到某行暂停 | 点击行号 |
| **条件断点** | 满足条件才暂停 | 右键行号 → Add conditional breakpoint |
| **日志断点** | 不暂停，只打印日志 | 右键行号 → Add logpoint |
| **DOM 断点** | DOM 变化时暂停 | Elements 右键 → Break on |
| **XHR 断点** | 请求匹配 URL 时暂停 | XHR/Fetch Breakpoints → Add |
| **事件断点** | 事件触发时暂停 | Event Listener Breakpoints |
| **异常断点** | 抛出异常时暂停 | 暂停按钮 → Pause on exceptions |

### 2. 调试控制

```text
调试快捷键：
F8 / Ctrl+\    继续执行（Resume）
F10 / Ctrl+'   跳过下一步（Step over）
F11 / Ctrl+;   进入函数（Step into）
Shift+F11      跳出函数（Step out）
Ctrl+F8        禁用所有断点

调试面板：
- Watch：添加监视表达式
- Call Stack：调用栈
- Scope：当前作用域变量（Local/Closure/Global）
- Breakpoints：所有断点列表
- XHR/fetch Breakpoints：请求断点
- DOM Breakpoints：DOM 断点
- Event Listener Breakpoints：事件断点
```

### 3. 工作区（Workspaces）

```text
将本地文件夹映射到浏览器，实现浏览器内编辑并保存到磁盘：
1. Filesystem 标签 → Add folder to workspace
2. 选择项目目录
3. 浏览器中编辑 CSS/JS → Ctrl+S 保存到本地
4. 配合 Source Maps 调试源码
```

### 4. 代码片段（Snippets）

```text
Sources → Snippets → New snippet
保存常用脚本，可随时运行：
- 清除所有 Cookie
- 导出 localStorage
- 注入调试脚本
- 性能测试脚本
```

## 五、Network 面板

### 1. 请求分析

```text
请求列表列说明：
- Name：文件名
- Status：状态码
- Type：类型（xhr/fetch/script/stylesheet/img...）
- Initiator：发起者
- Size：大小（传输大小 / 解压后大小）
- Time：总耗时
- Waterfall：时间瀑布图

筛选：
- 按类型筛选（All/Fetch/XHR/JS/CSS/Img/Media/Font/Doc/Ws/Other）
- 按文本搜索（过滤框输入关键词）
- 按域名筛选（输入 domain:example.com）
- 按状态码筛选（输入 status-code:200）
- 按大小筛选（输入 larger-than:100000）
```

### 2. 请求详情

```text
点击请求查看详情：
- Headers：请求头、响应头、查询参数
- Payload：请求体（POST 数据）
- Preview：响应预览（JSON/HTML/图片）
- Response：响应原始内容
- Timing：请求各阶段耗时
  - Queueing：排队时间
  - Stalled：等待可用连接
  - DNS Lookup：DNS 解析
  - Initial connection / TCP：TCP 连接
  - SSL：SSL 握手
  - Request sent：请求发送
  - Waiting (TTFB)：等待首字节
  - Content Download：内容下载
- Cookies：请求和响应的 Cookie
- Initiator：调用栈
```

### 3. 网络调试技巧

```text
- Disable cache：勾选后禁用缓存（DevTools 打开时）
- Throttling：模拟网络（Slow 3G/Fast 3G/Offline/自定义）
- 右键请求 → Copy → Copy as cURL / Copy as fetch / Copy response
- 右键请求 → Block request URL：阻止请求
- 右键请求 → Replay XHR：重发请求
- 右键请求 → Open in new tab：新标签打开
- Export HAR：导出所有请求为 HAR 文件
- 点击请求 → Override content：本地覆盖响应内容
```

### 4. 性能指标

```text
Network 面板底部：
- 请求数 / 传输大小 / 资源大小
- Finish：所有请求完成时间
- DOMContentLoaded：DOM 解析完成（蓝色线）
- Load：页面完全加载（红色线）
```

## 六、Performance 面板

### 1. 录制性能

```text
1. 打开 Performance 面板
2. 点击录制按钮（或 Ctrl+E）
3. 操作页面（滚动、点击等）
4. 停止录制
5. 分析结果
```

### 2. 性能分析视图

```text
面板区域：
- 概览（Overview）：FPS/CPU/网络 三条曲线
- 网络（Network）：请求瀑布图
- 帧（Frames）：每帧渲染时间（绿色<16ms 良好，红色>16ms 卡顿）
- 交互（Interactions）：用户交互事件
- 主线程（Main）：JS 执行、样式计算、布局、绘制
  - 黄色：JS 执行
  - 紫色：样式计算（Recalculate Style）
  - 绿色：布局（Layout）
  - 紫色偏红：绘制（Paint）
  - 深绿：合成（Composite）
- Raster：光栅化线程
- GPU：GPU 进程
- Memory：内存变化（需勾选）
```

### 3. 性能诊断

```text
常见性能问题：
- 长任务（Long Task）：JS 执行超过 50ms，阻塞主线程
- 强制同步布局（Forced Reflow）：JS 读取布局属性后立即修改
- 布局抖动（Layout Thrashing）：反复读写布局属性
- 重绘（Paint）：频繁修改非布局属性
- 内存泄漏：内存持续增长不下降

优化方向：
- JS：拆分长任务、使用 requestIdleCallback、Web Worker
- CSS：减少重排、使用 transform/opacity（GPU 加速）
- 渲染：使用 will-change、contain
- 图片：懒加载、使用合适格式
```

## 八、Lighthouse 审计

### 1. 审计维度

| 维度 | 说明 | 权重 |
|------|------|------|
| **Performance** | 加载和运行性能 | 高 |
| **Accessibility** | 可访问性 | 中 |
| **Best Practices** | 最佳实践 | 中 |
| **SEO** | 搜索引擎优化 | 中 |
| **PWA** | 渐进式 Web 应用 | 可选 |

### 2. 核心性能指标

```text
LCP（Largest Contentful Paint）：最大内容绘制，<2.5s 良好
FID（First Input Delay）：首次输入延迟，<100ms 良好（已被 INP 替代）
INP（Interaction to Next Paint）：交互到下一次绘制，<200ms 良好
CLS（Cumulative Layout Shift）：累积布局偏移，<0.1 良好
TTFB（Time to First Byte）：首字节时间，<800ms 良好
```

### 3. 使用建议

```text
- 使用无痕模式运行（排除扩展干扰）
- 模拟移动端（默认 Mobile）
- 多次运行取平均值
- 关注 Opportunities 和 Diagnostics 部分的具体建议
```

## 十、最佳实践

### 1. 调试规范

- [ ] **Console 分级**：合理使用 log/warn/error，生产环境清理
- [ ] **断点优先**：用断点而非 console.log 调试复杂逻辑
- [ ] **条件断点**：循环中用条件断点，避免逐次暂停
- [ ] **日志断点**：临时调试用 logpoint，不修改代码
- [ ] **Source Maps**：生产环境部署 Source Map（安全存储）
- [ ] **无痕调试**：性能测试用无痕模式，排除扩展干扰

### 2. 性能分析规范

- [ ] **禁用缓存**：性能分析时勾选 Disable cache
- [ ] **模拟网络**：用 Throttling 模拟弱网
- [ ] **多次测量**：性能数据多次运行取平均
- [ ] **关注主线程**：Main 线程火焰图是性能分析核心
- [ ] **Lighthouse 审计**：定期运行 Lighthouse 跟踪指标
- [ ] **Core Web Vitals**：关注 LCP/INP/CLS 三大指标

### 3. 安全规范

- [ ] **敏感信息**：不在控制台输出密码、Token 等敏感信息
- [ ] **生产环境**：生产环境禁用调试代码（Source Map 不公开）
- [ ] **XSS 防护**：控制台执行的代码注意安全
- [ ] **Cookie 安全**：HttpOnly Cookie 无法通过 JS 读取

## 十一、常见问题与排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| **断点不生效** | Source Map 未加载 / 代码被压缩 | 检查 Source Map、使用格式化按钮 |
| **样式不生效** | 被更高优先级覆盖 / 缓存 | Computed 面板查看来源、禁用缓存 |
| **请求看不到** | 筛选器开启 / 保留日志未开 | 清除筛选、勾选 Preserve log |
| **页面白屏** | JS 报错 / 资源加载失败 | Console 看错误、Network 看失败请求 |
| **样式闪烁** | CSS 加载顺序 / FOUT | 关键 CSS 内联、预加载字体 |
| **内存泄漏** | 未清理事件监听 / 闭包 | Memory 面板拍快照对比 |
| **FPS 低** | 长任务 / 频繁重排 | Performance 面板分析主线程 |
| **跨域报错** | CORS 未配置 | 检查响应头 Access-Control-Allow-Origin |
| **Cookie 不发送** | SameSite / 跨域 | 检查 SameSite 属性、withCredentials |
| **移动端调试失败** | 驱动未装 / USB 调试未开 | 安装驱动、开启开发者选项 |
| **Lighthouse 分数低** | 资源大 / 渲染慢 | 按 Opportunities 建议逐项优化 |
| **本地覆盖不生效** | 目录未授权 / 匹配失败 | 重新选择目录、检查 URL 匹配 |
| **控制台 $ 不工作** | 页面覆盖了 $ 变量（如 jQuery） | 使用 $$() 或 document.querySelector |
| **Network 显示 (from disk cache)** | 缓存命中 | 正常现象，Disable cache 可禁用 |
| **元素无法选中** | 有遮罩层 / pointer-events | 移除遮罩或在 Elements 中直接找 |
