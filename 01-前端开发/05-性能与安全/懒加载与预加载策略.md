# 懒加载与预加载策略

> **文档说明**：系统讲解前端懒加载与预加载策略，包括图片/组件/代码/数据/视频/字体的懒加载，以及 preload/prefetch/preconnect/dns-prefetch 预加载策略，配合性能指标和最佳实践。

## 一、概述

### 1. 为什么需要懒加载和预加载

```text
核心矛盾：
- 首屏加载时间有限（用户期望 < 3s）
- 现代 Web 应用资源越来越大（JS/CSS/图片/字体/视频）
- 一次性加载所有资源 → 首屏慢、流量浪费、体验差

解决方案：
- 懒加载（Lazy Loading）：延迟加载非关键资源，需要时再加载
- 预加载（Preloading）：提前加载关键资源，需要时立即可用

两者配合：
- 首屏关键资源 → 预加载（尽快加载）
- 非首屏资源 → 懒加载（需要时加载）
- 可能用到的资源 → 预获取（空闲时加载）

效果：
- 首屏加载时间减少 30-70%
- 流量节省（用户不访问的内容不加载）
- 用户体验提升（内容渐进式呈现）
```

### 2. 资源加载策略矩阵

```text
资源加载优先级策略：

┌─────────────────────────────────────────────────┐
│              资源加载策略矩阵                      │
├──────────┬──────────────────────────────────────┤
│  策略     │  适用场景                             │
├──────────┼──────────────────────────────────────┤
│ 立即加载  │  首屏关键资源（HTML/CSS/首屏JS/字体） │
│ preload   │  当前页面即将用到的关键资源            │
│ prefetch  │  下一页面可能用到的资源（空闲加载）    │
│ preconnect│  即将请求的第三方域名（提前建连）      │
│ dns-prefetch │ 未来可能请求的域名（DNS解析）     │
│ 懒加载    │  非首屏资源（图片/组件/路由/视频）    │
│ 按需加载  │  用户操作触发的资源（弹窗/抽屉/工具）  │
└──────────┴──────────────────────────────────────┘

关键原则：
- 关键路径资源：尽快加载（preload / 内联）
- 非关键资源：懒加载
- 预测资源：prefetch（浏览器空闲时）
- 第三方域名：preconnect / dns-prefetch
```

## 二、图片懒加载

### 1. 原生懒加载

```html
<!-- 原生 loading="lazy"（最简单，浏览器支持） -->
<img
  src="image.jpg"
  alt="描述"
  loading="lazy"
  width="800"
  height="600"
/>

<!-- loading 属性值：
  - auto：浏览器默认行为
  - lazy：懒加载（进入视口前不加载）
  - eager：立即加载
-->

<!-- iframe 也支持 -->
<iframe src="video.html" loading="lazy"></iframe>

优点：
- 零成本，原生支持
- 浏览器优化（加载时机更合理）
- 无需 JS

缺点：
- 不支持占位符/过渡动画
- 旧浏览器不支持（IE、旧版 Safari）
- 加载时机不可控
```

### 2. IntersectionObserver 实现

```javascript
// 通用图片懒加载（IntersectionObserver）
class LazyImageLoader {
  constructor(options = {}) {
    this.options = {
      rootMargin: '200px 0px',  // 提前 200px 加载
      threshold: 0.01,
      ...options
    }
    this.observer = null
    this.init()
  }

  init() {
    if (!('IntersectionObserver' in window)) {
      // 降级：直接加载所有图片
      document.querySelectorAll('img[data-src]').forEach(img => this.loadImage(img))
      return
    }

    this.observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          this.loadImage(entry.target)
          this.observer.unobserve(entry.target)
        }
      })
    }, this.options)
  }

  loadImage(img) {
    const src = img.dataset.src
    if (!src) return

    // 显示加载占位
    img.classList.add('lazy-loading')

    const tempImg = new Image()
    tempImg.onload = () => {
      img.src = src
      img.classList.remove('lazy-loading')
      img.classList.add('lazy-loaded')
      // 移除 data-src，避免重复处理
      img.removeAttribute('data-src')
    }
    tempImg.onerror = () => {
      img.classList.remove('lazy-loading')
      img.classList.add('lazy-error')
    }
    tempImg.src = src
  }

  observe(img) {
    if (this.observer) {
      this.observer.observe(img)
    } else {
      this.loadImage(img)
    }
  }

  observeAll(selector = 'img[data-src]') {
    document.querySelectorAll(selector).forEach(img => this.observe(img))
  }
}

// 使用
const loader = new LazyImageLoader({ rootMargin: '300px 0px' })
loader.observeAll()
```

### 3. 响应式图片懒加载

```html
<!-- srcset + sizes 响应式图片 -->
<img
  data-src="image-small.jpg"
  data-srcset="
    image-small.jpg 400w,
    image-medium.jpg 800w,
    image-large.jpg 1200w
  "
  data-sizes="(max-width: 600px) 400px, (max-width: 1000px) 800px, 1200px"

// 懒加载时设置 srcset
function loadImage(img) {
  if (img.dataset.srcset) {
    img.srcset = img.dataset.srcset
    img.sizes = img.dataset.sizes || ''
  }
  if (img.dataset.src) {
    img.src = img.dataset.src
  }
}
</script>
```

### 4. Vue3 图片懒加载指令

```typescript
// src/directives/lazy.ts
import type { Directive } from 'vue'

interface LazyElement extends HTMLImageElement {
  _lazyObserver?: IntersectionObserver
}

export const lazyDirective: Directive<LazyElement, string> = {
  mounted(el, binding) {
    el.dataset.src = binding.value
    el.classList.add('lazy-loading')

    // 占位图
    el.src = 'data:image/svg+xml,...'  // 透明占位

    const observer = new IntersectionObserver(
      (entries) => {
        entries.forEach(entry => {
          if (entry.isIntersecting) {
            const img = entry.target as LazyElement
            const src = img.dataset.src
            if (src) {
              const tempImg = new Image()
              tempImg.onload = () => {
                img.src = src
                img.classList.remove('lazy-loading')
                img.classList.add('lazy-loaded')
              }
              tempImg.src = src
            }
            observer.unobserve(img)
          }
        })
      },
      { rootMargin: '200px 0px' }
    )

    observer.observe(el)
    el._lazyObserver = observer
  },

  updated(el, binding) {
    if (binding.value !== binding.oldValue) {
      el.dataset.src = binding.value
      // 如果已经在视口中，重新加载
      el.classList.add('lazy-loading')
      const tempImg = new Image()
      tempImg.onload = () => {
        el.src = binding.value
        el.classList.remove('lazy-loading')
        el.classList.add('lazy-loaded')
      }
      tempImg.src = binding.value
    }
  },

  unmounted(el) {
    el._lazyObserver?.disconnect()
  }
}
```

```vue
<!-- 使用 -->
<template>
  <img v-lazy="imageUrl" alt="描述" />
</template>

<script setup>
import { lazyDirective } from '@/directives/lazy'
</script>
```

### 2. 路由懒加载

import { createRouter, createWebHistory } from 'vue-router'

const routes = [

    path: '/',

### 3. 路由预加载

```typescript
// 路由导航时预加载下一个页面
router.beforeEach((to, from, next) => {
  // 预加载目标路由组件
  const matchedComponents = to.matched.flatMap(record =>
    Object.values(record.components || {})
  )

  matchedComponents.forEach(component => {
    if (typeof component === 'function') {
      // 触发异步组件加载
      component()
    }
  })

  next()
})

// 或者在链接 hover 时预加载
// <router-link @mouseenter="preload('/about')">关于</router-link>
function preload(path) {
  const route = router.resolve(path)
  route.matched.forEach(record => {
    Object.values(record.components || {}).forEach(comp => {
      if (typeof comp === 'function') comp()
    })
  })
}
```

## 五、预加载策略

### 1. preload（预加载当前页面资源）

```html
<!-- preload：提前加载当前页面即将用到的关键资源 -->

<!-- 预加载关键 JS -->
<link rel="preload" href="/js/app.js" as="script" />

<!-- 预加载关键 CSS -->
<link rel="preload" href="/css/main.css" as="style" />

<!-- 预加载字体（带 crossorigin） -->
<link
  rel="preload"
  href="/fonts/Inter.woff2"
  as="font"
  type="font/woff2"
  crossorigin
/>

<!-- 预加载图片（首屏大图） -->
<link rel="preload" href="/images/hero.jpg" as="image" />

<!-- 预加载视频 -->
<link rel="preload" href="/video/intro.mp4" as="video" />

<!-- 预加载 fetch 请求的数据 -->
<link rel="preload" href="/api/config" as="fetch" crossorigin />

<!-- media 属性：根据条件预加载 -->
<link
  rel="preload"
  href="/images/banner-mobile.jpg"
  as="image"
  media="(max-width: 600px)"
/>

<!-- as 属性值：
  script / style / image / font / video / audio /
  fetch / document / worker / embed / object
-->
```

```javascript
// 动态 preload
function preloadResource(href, as) {
  const link = document.createElement('link')
  link.rel = 'preload'
  link.href = href
  link.as = as
  if (as === 'font') link.crossOrigin = 'anonymous'
  document.head.appendChild(link)
}

// 用户 hover 导航时预加载
document.querySelectorAll('nav a').forEach(link => {
  link.addEventListener('mouseenter', () => {
    preloadResource(link.href, 'document')
  })
})
```

### 2. prefetch（预获取下一页面资源）

```html
<!-- prefetch：浏览器空闲时预获取未来可能用到的资源 -->

<!-- 预获取下一个页面的 JS -->
<link rel="prefetch" href="/js/about.js" />

<!-- 预获取图片 -->
<link rel="prefetch" href="/images/next-banner.jpg" />

<!-- 预获取字体 -->
<link rel="prefetch" href="/fonts/Inter-Bold.woff2" as="font" crossorigin />
```

```text
preload vs prefetch：

preload：
- 用于当前页面
- 高优先级，立即加载
- 不加载会影响当前页面
- 有 as 属性，浏览器知道资源类型

prefetch：
- 用于下一个页面/未来导航
- 低优先级，浏览器空闲时加载
- 不影响当前页面
- 可以没有 as 属性
- 缓存时间较长（5分钟）
```

### 3. preconnect（提前建立连接）

```html
<!-- preconnect：提前与第三方域名建立连接（DNS + TCP + TLS） -->

<!-- 预连接 Google Fonts -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />

<!-- 预连接 API 域名 -->
<link rel="preconnect" href="https://api.example.com" />

<!-- 预连接 CDN -->
<link rel="preconnect" href="https://cdn.example.com" />

<!-- 预连接视频流媒体 -->
<link rel="preconnect" href="https://video.example.com" crossorigin />
```

```text
preconnect 做了什么：
1. DNS 解析：域名 → IP
2. TCP 握手：建立 TCP 连接
3. TLS 握手：建立 HTTPS 加密连接

节省时间：通常 100-500ms（取决于网络和服务器）

注意：
- 只对即将请求的域名使用（1-3个即可）
- 太多 preconnect 会浪费资源
- 跨域资源需要 crossorigin 属性
- 连接只保持 10-15 秒，超时会关闭
```

### 4. dns-prefetch（DNS 预解析）

```html
<!-- dns-prefetch：只做 DNS 解析（比 preconnect 轻量） -->

<link rel="dns-prefetch" href="https://fonts.googleapis.com" />
<link rel="dns-prefetch" href="https://api.example.com" />
<link rel="dns-prefetch" href="https://cdn.example.com" />
<link rel="dns-prefetch" href="https://analytics.example.com" />
```

```text
dns-prefetch vs preconnect：

dns-prefetch：
- 只做 DNS 解析
- 轻量，几乎无成本
- 可以用于多个域名（5-10个）
- 适合未来可能请求的域名

preconnect：
- DNS + TCP + TLS
- 较重，消耗资源
- 只用于即将请求的域名（1-3个）
- 节省更多时间

策略：
- 即将请求的关键域名 → preconnect
- 可能请求的域名 → dns-prefetch
- 两者可以配合使用
```

## 六、数据懒加载

### 1. 无限滚动

```vue
<!-- 无限滚动列表 -->
<template>
  <div class="list-container" ref="containerRef">
    <div v-for="item in items" :key="item.id" class="list-item">
      {{ item.title }}
    </div>

    <!-- 加载状态 -->
    <div v-if="loading" class="loading">加载中...</div>
    <div v-if="!hasMore && items.length > 0" class="no-more">没有更多了</div>

    <!-- 哨兵元素 -->
    <div ref="sentinelRef" class="sentinel"></div>
  </div>
</template>

<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const containerRef = ref()
const sentinelRef = ref()
const items = ref([])
const loading = ref(false)
const hasMore = ref(true)
const page = ref(1)
const pageSize = 20

let observer = null

async function loadMore() {
  if (loading.value || !hasMore.value) return

  loading.value = true
  try {
    const data = await fetchItems(page.value, pageSize)
    items.value.push(...data.list)
    hasMore.value = data.hasMore
    page.value++
  } catch (error) {
    console.error('加载失败', error)
  } finally {
    loading.value = false
  }
}

onMounted(() => {
  observer = new IntersectionObserver(
    (entries) => {
      if (entries[0].isIntersecting) {
        loadMore()
      }
    },
    { rootMargin: '200px' }  // 提前 200px 触发
  )

  if (sentinelRef.value) {
    observer.observe(sentinelRef.value)
  }
})

onUnmounted(() => {
  observer?.disconnect()
})
</script>
```

### 2. 虚拟列表

```vue
<!-- 虚拟列表（只渲染可见区域） -->
<template>
  <div class="virtual-list" ref="containerRef" @scroll="handleScroll">
    <!-- 占位高度 -->
    <div :style="{ height: totalHeight + 'px' }">
      <!-- 可见区域 -->
      <div :style="{ transform: `translateY(${offsetY}px)` }">
        <div
          v-for="item in visibleItems"
          :key="item.id"
          :style="{ height: itemHeight + 'px' }"
          class="list-item"
        >
          {{ item.title }}
        </div>
      </div>
    </div>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'

const props = defineProps({
  items: { type: Array, required: true },
  itemHeight: { type: Number, default: 50 },
  containerHeight: { type: Number, default: 500 }
})

const containerRef = ref()
const scrollTop = ref(0)

const totalHeight = computed(() => props.items.length * props.itemHeight)

const startIndex = computed(() =>
  Math.floor(scrollTop.value / props.itemHeight)
)

const endIndex = computed(() =>
  Math.min(
    startIndex.value + Math.ceil(props.containerHeight / props.itemHeight) + 2,
    props.items.length
  )
)

const visibleItems = computed(() =>
  props.items.slice(startIndex.value, endIndex.value)
)

const offsetY = computed(() => startIndex.value * props.itemHeight)

function handleScroll(e) {
  scrollTop.value = e.target.scrollTop
}
</script>
```

## 七、视频与音频懒加载

```html
<!-- 视频懒加载 -->
<video
  controls
  preload="none"        <!-- 不预加载任何数据 -->
  poster="thumbnail.jpg" <!-- 缩略图 -->
  data-src="video.mp4"
  class="lazy-video"
>
  <source data-src="video.mp4" type="video/mp4" />
  <source data-src="video.webm" type="video/webm" />
</video>

<!-- preload 属性：
  - none：不预加载（最省流量）
  - metadata：只加载元数据（时长、尺寸）
  - auto：浏览器决定（可能预加载全部）
-->

<script>
// 视频进入视口时加载
const videoObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const video = entry.target
      const sources = video.querySelectorAll('source[data-src]')
      sources.forEach(source => {
        source.src = source.dataset.src
      })
      video.load()  // 重新加载
      videoObserver.unobserve(video)
    }
  })
}, { rootMargin: '200px' })

document.querySelectorAll('.lazy-video').forEach(video => {
  videoObserver.observe(video)
})
</script>

<!-- 音频懒加载 -->
<audio controls preload="none" data-src="audio.mp3" class="lazy-audio">
</audio>
```

## 九、性能指标与监控

```text
懒加载/预加载相关性能指标：

1. LCP（Largest Contentful Paint）
   - 最大内容绘制时间
   - 目标：< 2.5s
   - 优化：首屏图片 preload、字体 preload、关键 CSS 内联

2. FID（First Input Delay）→ INP
   - 首次输入延迟 / 交互到下一次绘制
   - 目标：< 100ms（FID）/ < 200ms（INP）
   - 优化：JS 代码分割、懒加载非关键 JS、避免长任务

3. CLS（Cumulative Layout Shift）
   - 累积布局偏移
   - 目标：< 0.1
   - 优化：图片设置 width/height、懒加载占位符、字体 font-display: swap

4. TTFB（Time to First Byte）
   - 首字节时间
   - 目标：< 800ms
   - 优化：CDN、缓存、服务端性能

5. 资源加载指标
   - 首屏资源大小：< 200KB（JS+CSS+图片）
   - 请求数：< 30（首屏）
   - 懒加载资源比例：> 50%

监控工具：
- Lighthouse：审计性能
- WebPageTest：详细加载瀑布图
- Chrome DevTools：Performance/Network 面板
- 真实用户监控（RUM）：Google Analytics / 自建
```

## 十、最佳实践

### 1. 懒加载最佳实践

- [ ] **图片设置宽高**：避免 CLS，设置 width/height 或 aspect-ratio
- [ ] **占位符**：用模糊占位图或骨架屏，提升感知体验
- [ ] **rootMargin**：提前 200-300px 加载，用户无感
- [ ] **首屏图片不懒加载**：首屏关键图片用 preload 或 eager
- [ ] **SEO 考虑**：懒加载图片确保 src 有默认值，或用 noscript 兜底
- [ ] **无障碍**：确保键盘导航和屏幕阅读器正常工作
- [ ] **离线支持**：Service Worker 缓存已加载资源
- [ ] **大图优化**：WebP/AVIF 格式、响应式图片、渐进式加载
- [ ] **视频用 poster**：视频缩略图，preload="none"

### 2. 预加载最佳实践

- [ ] **只 preload 关键资源**：1-3 个，太多浪费带宽
- [ ] **preload 必须使用**：preload 的资源必须在当前页面用到，否则浪费
- [ ] **字体带 crossorigin**：字体 preload 必须加 crossorigin
- [ ] **preconnect 关键域名**：1-3 个即将请求的第三方域名
- [ ] **dns-prefetch 其他域名**：可能请求的域名都可以加
- [ ] **prefetch 下一页面**：用户可能导航到的页面资源
- [ ] **hover 预加载**：导航链接 hover 时预加载目标页面
- [ ] **媒体查询预加载**：根据设备条件预加载不同资源
- [ ] **避免 preload 和 prefetch 重复**：同一资源不要同时用

### 3. 综合策略

```text
推荐的资源加载策略：

首屏关键资源：
- HTML：立即加载
- 关键 CSS：内联到 HTML（<style>）
- 首屏 JS：preload + 内联关键部分
- 首屏图片：preload + eager
- 首屏字体：preload + font-display: swap
- 关键 API：preconnect 域名

非首屏资源：
- 图片：loading="lazy" / IntersectionObserver
- 组件：defineAsyncComponent
- 路由：动态 import
- 视频：preload="none" + 进入视口加载
- 大库（图表/编辑器）：动态 import
- 非关键字体：font-display: swap，不 preload

预测资源：
- 下一页面：prefetch
- 导航 hover：preload 目标页面
- 可能的第三方域名：dns-prefetch
- 即将请求的域名：preconnect
```

## 十一、常见问题与排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| **懒加载图片空白** | 占位图未设置 / 加载失败 | 设置占位图、错误处理、检查 src 路径 |
| **布局偏移（CLS）** | 图片未设置宽高 | 设置 width/height 或 aspect-ratio、占位符 |
| **preload 资源未使用** | preload 了不需要的资源 | 只 preload 当前页面关键资源、移除未使用的 |
| **preload 字体 CORS 错误** | 未加 crossorigin | 字体 preload 必须加 crossorigin="anonymous" |
| **懒加载图片 SEO 问题** | 爬虫不执行 JS | 用原生 loading="lazy"、noscript 兜底、src 有默认值 |
| **无限滚动重复加载** | 防抖/状态管理问题 | 加 loading 锁、hasMore 判断、去重 |
| **虚拟列表滚动卡顿** | 渲染太多 / 计算复杂 | 优化渲染、requestAnimationFrame、缓存计算 |
| **prefetch 浪费流量** | prefetch 了用户不会访问的资源 | 只 prefetch 高概率访问的、按用户行为预测 |
| **preconnect 连接关闭** | 连接超时（10-15s） | 只对即将请求的域名 preconnect、请求前重新 preconnect |
| **首屏图片加载慢** | 未 preload / 图片太大 | preload 首屏图、压缩图片、WebP/AVIF、CDN |
| **JS 执行阻塞渲染** | 首屏 JS 太大 | 代码分割、懒加载非关键 JS、defer/async |
| **字体闪烁（FOUT）** | font-display: swap 正常现象 | 可接受，或用 font-display: optional（但可能不加载自定义字体） |
| **视频自动播放失败** | 浏览器策略（静音才能自动播放） | muted + autoplay、或用户交互后播放 |
| **IntersectionObserver 不支持** | 旧浏览器 | 降级为 scroll 事件监听、或直接加载 |
| **懒加载组件闪烁** | 加载状态未处理 | 配置 loadingComponent、delay 避免闪烁 |
| **路由切换白屏** | 异步组件加载慢 | prefetch 下一路由、loading 状态、骨架屏 |
| **preload 优先级不对** | as 属性错误 | 确保 as 属性正确（script/style/image/font） |
| **第三方脚本阻塞** | 同步加载第三方脚本 | async/defer、延迟加载、preconnect |
| **图片格式不兼容** | WebP/AVIF 旧浏览器不支持 | <picture> 多格式降级、JPEG 兜底 |
| **内存泄漏** | Observer 未销毁 | 组件卸载时 disconnect observer、清理事件监听 |
