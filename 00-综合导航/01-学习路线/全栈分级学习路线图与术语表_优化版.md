## 一、各板块学习路径与难度分级

| 板块 | 入门路径 | 难度 |
|------|----------|------|
| 01 前端 | HTML/CSS/JS → TS → React/Vue → 构建/工程化 | ⭐⭐⭐ |
| 02 后端(Java) | Java 语法 → 集合/并发 → Spring Boot → JVM | ⭐⭐⭐⭐ |
| 03 数据库 | SQL → 索引/事务 → Redis → 分库分表 | ⭐⭐⭐ |
| 04 分布式 | 消息队列 → 锁/ID → ES/Kafka → 一致性 | ⭐⭐⭐⭐⭐ |
| 05 云原生 | Docker → K8s → CI/CD → 可观测/IaC | ⭐⭐⭐⭐ |
| 06 计算机基础 | 计网 → OS → 算法 → 组成/编译 | ⭐⭐⭐⭐ |
| 08 Python | 语法 → 并发 → 类型 → Web/全栈 | ⭐⭐⭐ |
| 09 AI | Prompt → RAG → Agent → 部署/微调 | ⭐⭐⭐⭐ |

💡 **深度讲解**：难度来自「抽象层数」——分布式与底层原理抽象高、排错难，故 ⭐⭐⭐⭐⭐；前端入门低但深水区（性能/框架）仍高。
📝 **精简总结**：按「先广后深」；每板块先跑通最小例子再啃原理；难度高的配排查手册兜底。
🔍 **知识点深度解析**：作用=知道从哪学；原理=认知负荷梯度；要点=路径 + 难度透明。

## 二、零基础全栈入门路线图

### 2.1 12 周路线
```text
W1-2   前端三件套(HTML/CSS/JS) + Git
W3-4   TypeScript + React 基础 + 一个小页面
W5-6   Java/Python 语法 + 写 CRUD
W7-8   数据库 SQL + Spring Boot / FastAPI 接前端
W9-10  Linux + Docker 把应用跑起来
W11-12 部署到云 + 一个完整小项目(博客/待办)
```
进阶：算法 → 计网/OS → 分布式 → AI 工程化（对应 06/04/09 大全）

💡 **深度讲解**：零基础最忌「同时学太多」。路线按「前端可见 → 后端可存 → 运维可跑」递进，每步都有可演示成果，保持正反馈。
📝 **精简总结**：先做出能跑的东西；W1-8 打通全栈最小闭环；W9-12 上云；之后按兴趣钻深。
🔍 **知识点深度解析**：作用=降低弃学率；原理=成就驱动；要点=小闭环 + 即时反馈。

## 四、术语表（Glossary）

| 术语 | 含义 | 关联板块 |
|------|------|----------|
| SSE | 服务端推送事件流 | 前端/AI |
| RAG | 检索增强生成 | AI |
| MCP | 模型上下文协议(工具总线) | AI/IDE |
| 水合 Hydration | SSR 后客户端接管 | 前端 |
| 死锁 | 互相等待对方锁 | 数据库/并发 |
| 一致性哈希 | 节点变动影响最小 | 分布式 |
| 可观测性 | Metrics/Logs/Traces | 云原生 |
| 伪共享 | 同缓存行互踢 | 计算机基础 |
| 雪崩 | 大量缓存同时失效 | 数据库 |
| SLO | 服务等级目标 | 云原生 |

💡 **深度讲解**：术语表是跨板块「通用语言」；同一词在不同语境可能侧重不同（如「锁」在 DB 与并发中机制不同），需结合板块理解。
📝 **精简总结**：遇到黑话先查表；跨板块术语注意语境；建议随学随补。
🔍 **知识点深度解析**：作用=统一认知；原理=词汇即概念；要点=语境敏感。

## 五、跨板块概念地图

```text
                计算机基础(06)
              /    |    |    \
        算法    OS    计网   组成/编译
          \     |     |      /
           ├── 后端(02) ── 数据库(03) ── 分布式(04)
           │        \           /
           │         AI(09) ───┘
           └── 前端(01) ── 交互
                    │
              云原生(05) ── 承载全部
```

💡 **深度讲解**：概念地图展示「底层基础支撑上层、各栈通过数据/协议互联」。计算机基础是根，云原生是承载，AI/前端/后端是应用面。
📝 **精简总结**：先固底层(06)再爬上层；板块间靠「数据(库)/协议(网)/编排(云)」相连；本图即知识库导航心智。
🔍 **知识点深度解析**：作用=建立全局观；原理=依赖层次；要点=根固 + 互联。
