# 算法刷题指南与题型模板

> **文档说明**：面向算法零基础到面试水平的完整刷题路线，涵盖题型分类、解题模板、推荐题单、学习方法。按此路线3个月可达到互联网大厂面试算法水平。
>
> **适用人群**：算法新手、准备面试的开发者

---

## 一、概述

算法是程序员面试的必考项，也是提升编程思维的核心训练。本文提供一套系统化的刷题方法，不需要刷几百题，掌握核心题型和模板就能应对90%的面试题。

### 刷题原则

1. **按题型刷**：不要随机刷题，按数据结构和算法类型集中突破
2. **先理解后写**：先想清楚思路，再动手写代码
3. **总结模板**：每种题型提炼通用模板，遇到类似题直接套用
4. **重复练习**：经典题做3遍以上，形成肌肉记忆
5. **限时训练**：面试前模拟限时，每题不超过30分钟

## 二、核心题型与解题模板

### 1. 数组与双指针

**适用场景**：有序数组、两数之和、去重、滑动窗口

```python
# 双指针模板
def two_pointers(arr):
    left, right = 0, len(arr) - 1
    while left < right:
        if condition(arr[left], arr[right]):
            left += 1
        else:
            right -= 1
    return result

# 滑动窗口模板
def sliding_window(arr, k):
    left = 0
    window = {}
    result = 0
    for right in range(len(arr)):
        # 扩大窗口
        window[arr[right]] = window.get(arr[right], 0) + 1
        # 缩小窗口
        while window_invalid():
            window[arr[left]] -= 1
            left += 1
        # 更新结果
        result = max(result, right - left + 1)
    return result
```

**必刷题**：两数之和、三数之和、移动零、无重复字符的最长子串、最小覆盖子串

### 2. 链表

**适用场景**：反转、环、合并、删除

```python
# 链表反转模板
def reverse_list(head):
    prev, curr = None, head
    while curr:
        next_node = curr.next
        curr.next = prev
        prev = curr
        curr = next_node
    return prev

# 快慢指针模板（找中点/环）
def fast_slow(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow  # 中点
```

**必刷题**：反转链表、合并两个有序链表、环形链表、链表中点、删除倒数第N个节点

### 3. 哈希表

**适用场景**：统计频次、查找、去重、两数之和

```python
# 哈希统计模板
def count_freq(arr):
    freq = {}
    for num in arr:
        freq[num] = freq.get(num, 0) + 1
    return freq
```

**必刷题**：两数之和、字母异位词、最长连续序列、前K个高频元素

### 4. 栈与队列

**适用场景**：括号匹配、单调栈、表达式求值、BFS

```python
# 单调栈模板（下一个更大元素）
def next_greater(arr):
    stack = []
    result = [-1] * len(arr)
    for i in range(len(arr)):
        while stack and arr[stack[-1]] < arr[i]:
            result[stack.pop()] = arr[i]
        stack.append(i)
    return result

# BFS模板
from collections import deque
def bfs(root):
    queue = deque([root])
    visited = set()
    while queue:
        node = queue.popleft()
        if node in visited: continue
        visited.add(node)
        for neighbor in node.neighbors:
            queue.append(neighbor)
```

**必刷题**：有效的括号、每日温度、最小栈、二叉树层序遍历、岛屿数量

### 5. 二叉树

**适用场景**：遍历、路径、公共祖先、翻转

```python
# DFS递归模板
def dfs(node):
    if not node:
        return 0  # 或默认值
    # 前序：处理node
    left = dfs(node.left)
    # 中序
    right = dfs(node.right)
    # 后序：处理node
    return combine(left, right)

# 层序遍历
from collections import deque
def level_order(root):
    if not root: return []
    queue, result = deque([root]), []
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        result.append(level)
    return result
```

**必刷题**：二叉树的最大深度、前中后序遍历、翻转二叉树、对称二叉树、最近公共祖先、路径总和

### 6. 动态规划

**适用场景**：最值问题、计数问题、子序列问题

```python
# DP模板
def dp_solution(nums):
    n = len(nums)
    # 1. 定义dp：dp[i]表示前i个元素的...
    dp = [0] * (n + 1)
    # 2. 初始化
    dp[0] = 0
    # 3. 状态转移
    for i in range(1, n + 1):
        dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
    # 4. 返回结果
    return dp[n]

# 空间优化（只依赖前两个状态）
def dp_optimized(nums):
    prev2, prev1 = 0, 0
    for num in nums:
        curr = max(prev1, prev2 + num)
        prev2, prev1 = prev1, curr
    return prev1
```

**必刷题**：爬楼梯、斐波那契、最大子数组和、零钱兑换、最长递增子序列、编辑距离、背包问题

### 8. 贪心

**适用场景**：区间问题、跳跃问题、分配问题

```python
# 贪心模板：每步选局部最优
def greedy(intervals):
    intervals.sort(key=lambda x: x[1])  # 按结束时间排序
    count = 1
    end = intervals[0][1]
    for interval in intervals[1:]:
        if interval[0] >= end:
            count += 1
            end = interval[1]
    return count
```

**必刷题**：跳跃游戏、买卖股票最佳时机、区间调度、分发饼干

### 9. 二分查找

**适用场景**：有序数组查找、搜索插入位置、最值问题

```python
# 二分查找模板
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1  # 或left（插入位置）

# 左边界二分
def left_bound(arr, target):
    left, right = 0, len(arr)
    while left < right:
        mid = (left + right) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

**必刷题**：二分查找、搜索插入位置、搜索旋转排序数组、寻找峰值、x的平方根

### 10. 图论

**适用场景**：最短路径、拓扑排序、连通性

```python
# DFS图遍历
def dfs_graph(graph, node, visited):
    if node in visited: return
    visited.add(node)
    for neighbor in graph[node]:
        dfs_graph(graph, neighbor, visited)

# 拓扑排序（Kahn算法）
from collections import deque
def topo_sort(n, edges):
    indegree = [0] * n
    graph = [[] for _ in range(n)]
    for u, v in edges:
        graph[u].append(v)
        indegree[v] += 1
    queue = deque([i for i in range(n) if indegree[i] == 0])
    result = []
    while queue:
        node = queue.popleft()
        result.append(node)
        for neighbor in graph[node]:
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                queue.append(neighbor)
    return result if len(result) == n else []
```

**必刷题**：岛屿数量、课程表、克隆图、最短路径、网络延迟时间

## 五、刷题方法

### 5步刷题法

1. **读题**：理解题意，明确输入输出和约束
2. **想思路**：先想暴力解法，再想优化，5分钟没思路直接看题解
3. **写代码**：按思路实现，注意边界条件
4. **看题解**：对比最优解法，理解差异
5. **做笔记**：记录题型、思路、模板，一周后重做

### 错题本

每道错题记录：
- 题目和链接
- 错误原因（思路错/边界错/语法错）
- 正确思路
- 同类题链接
