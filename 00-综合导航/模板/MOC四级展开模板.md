# 🗺️ MOC 四级展开模板

> 用于生成各知识板块的四级展开内容地图。结构：一级板块 → 二级分类 → 三级知识点 → 四级子知识点。每个三级知识点对应一篇独立原子笔记，四级子知识点是笔记内部的核心章节。

---

## 模板正文（复制以下内容）

```markdown
---
title: <板块名> MOC（四级展开）
tags: [MOC, <板块标签前缀>, 枢纽]
created: YYYY-MM-DD
updated: YYYY-MM-DD
hub: true
---
```

## 填写说明

| 字段 | 说明 |
|------|------|
| `hub: true` | 标记为枢纽笔记，Obsidian 图谱中高亮显示 |
| 四级子知识点 | 是三级笔记内部的核心章节，不是独立文件；若某个四级点内容足够丰富，可拆分为独立笔记并在三级笔记中链接 |
| 推荐笔记文件名 | 遵循`<技术>-<主题>.md`命名，如 `FastAPI-依赖注入.md` |
| 学习依赖 | 用箭头表示先后顺序，跨板块依赖要标注目标板块 |
