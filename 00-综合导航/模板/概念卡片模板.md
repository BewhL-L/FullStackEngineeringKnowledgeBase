# 🃏 概念卡片模板

> 轻量级概念记录模板，适合快速捕捉单个概念，后续可扩展为完整原子化笔记。比原子化笔记更简洁，适合灵感记录和快速摄入。

---

## 模板正文（复制以下内容）

```markdown
---
title: <概念名>
tags: [<领域>, <技术>, 概念]
created: YYYY-MM-DD
source: <来源>
status: 草稿
---

# <概念名>

> <一句话定义>

## 一句话理解

<用最通俗的话解释这个概念，不超过2句话>

## 关键公式/代码

```<语言>
<核心代码或公式>
```

## 什么时候用

- 场景1：<什么时候应该用这个概念/技术>
- 场景2：<...>

## 关联

- 相关：[[概念A]] [[概念B]]
- 对比：[[概念C]]（区别是 <一句话>）
```

---

## 概念卡片 vs 原子化笔记

| 维度 | 概念卡片 | 原子化笔记 |
|------|----------|-----------|
| 篇幅 | 100-300字 | 500-1500字 |
| 深度 | 快速理解 | 深入掌握 |
| 结构 | 简化（4个部分） | 完整（6+个部分） |
| 适用 | 灵感记录、快速摄入 | 系统学习、深度整理 |
| 成熟度 | #草稿 / #待完善 | #已审核 / #精品 |
| 转化 | 可扩展为原子化笔记 | 最终形态 |

**使用建议**：
- 学到新概念但没时间深入 → 先写概念卡片
- 周末或用到时 → 将概念卡片扩展为原子化笔记
- 概念卡片积累到一定数量 → 周度重构时批量扩展

# Function Calling

> 让大模型输出结构化的函数调用参数，而不是自然语言回答。

## 一句话理解

你告诉模型"我有这些函数可以用"，模型根据用户问题决定调用哪个函数、传什么参数，你的代码执行函数后把结果返回给模型。

## 关键代码

```typescript
const response = await openai.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "北京今天天气怎么样？" }],
  tools: [{ type: "function", function: { name: "get_weather", parameters: {...} } }]
});
```

## 什么时候用

- 需要 AI 调用外部 API（查天气、查数据库、发邮件）
- 需要 AI 输出结构化数据（JSON、表单）
- 构建 AI Agent（工具调用是 Agent 的核心能力）

## 关联

- 相关：[[AI Agent 开发]] [[RAG 检索增强生成]]
- 对比：[[RAG]] 是检索知识，Function Calling 是执行操作
```
