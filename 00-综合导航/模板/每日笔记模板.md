# 📅 每日笔记模板

> 用于每日学习记录、灵感捕捉和 Inbox 快速摄入。每日笔记是知识的源头，定期由 AI 处理后转化为原子化笔记。

---

## 模板正文（复制以下内容）

```markdown
---
title: YYYY-MM-DD 每日笔记
tags: [每日笔记, Inbox]
created: YYYY-MM-DD
status: 待处理
---

# 📅 YYYY-MM-DD 每日笔记

### <主题1>
<学习内容记录，可以是原文摘抄、个人理解、代码片段>

### <主题2>
<...>

## 灵感记录

- 💡 <灵感1>
- 💡 <灵感2>

## 待处理 Inbox

- [ ] <待处理的知识条目1>
- [ ] <待处理的知识条目2>

## 今日代码片段

```<语言>
<今天写的值得记录的代码>
```

## 问题与疑问

- ❓ <问题1>（待研究）
- ❓ <问题2>（已解决：[[相关笔记]]）

- [ ] <计划1>

```

## 每日笔记的使用方式

### 1. 快速记录（随时）

- 学到新知识 → 记入「今日学习」
- 有灵感 → 记入「灵感记录」
- 遇到问题 → 记入「问题与疑问」
- 写了好代码 → 记入「今日代码片段」

### 2. 定期处理（每天/每周）

向 AI 发送指令：

```
处理 00-综合导航/每日笔记/2026-08-13每日笔记.md：
1. 提取其中的核心概念
2. 为每个概念生成概念卡片或原子化笔记
3. 归档到对应分类
4. 将本笔记 status 改为「已处理」
```

### 3. 回顾（每周/每月）

- 翻阅过去的每日笔记，看看有哪些灵感还没落地
- 检查「问题与疑问」是否已解决
- 统计本月学习了哪些主题

---

## 每日笔记命名与存储

```
存储位置：00-综合导航/每日笔记/
命名格式：YYYY-MM-DD每日笔记.md
示例：2026-08-13每日笔记.md
```

在 Obsidian 中可安装 **Daily Notes** 或 **Periodic Notes** 插件，一键创建当日笔记。

---

## 与 Inbox 的关系

```
每日笔记 ──(AI处理)──▶ 提取概念 ──▶ 原子化笔记 ──▶ 归档到分类
   │
   └── 原始记录保留，status 改为「已处理」
```

- 每日笔记是 Inbox 的一种形式（按日期聚合的 Inbox）
- 也可以单独创建 Inbox 笔记（如 `Inbox/2026-08-13-博客-xxx.md`）
- 两者并存：每日笔记用于日常碎片记录，单独 Inbox 用于完整文章/笔记的摄入
