## 跨板块关联类型

| 类型 | 说明 | 典型示例 |
|------|------|----------|
| 技术对接 | 两个技术栈通过API/协议连接 | Vue3 对接 FastAPI SSE、Java 封装 LLM 接口 |
| 概念迁移 | 一个板块的概念可以迁移到另一个板块 | 设计模式（Java↔Python）、响应式（前端↔后端） |
| 工具复用 | 工具链在多个板块通用 | Git、Docker、CI/CD 贯穿所有开发板块 |
| 架构整合 | 多板块共同组成完整系统架构 | 全栈项目 = 前端 + 后端 + AI + DevOps |
| 知识互补 | 两个板块的知识结合产生新理解 | CS基础 + AI工程 = 模型推理优化 |
