## 一、JavaScript

### Q1: 闭包是什么？应用场景？

**答案**：
- 闭包是函数和其词法环境的组合，函数可以访问定义时作用域中的变量
- 本质：函数执行后，作用域不被销毁，因为内部函数引用了外部变量
- 应用：数据私有化、函数柯里化、防抖节流、模块化
- 注意：闭包会导致内存泄漏（变量不被GC回收），需及时释放

```javascript
function counter() {
    let count = 0;  // 私有变量
    return {
        increment: () => ++count,
        getCount: () => count
    };
}
const c = counter();
c.increment(); // 1
c.getCount();  // 1
```

### Q2: 原型链？如何实现继承？

**答案**：
- 每个对象有`__proto__`指向构造函数的`prototype`
- 原型链：对象→原型→原型的原型→...→null
- 继承方式：
  - ES6 class extends（语法糖，推荐）
  - 组合继承（构造函数+原型链）
  - 寄生组合继承（最优）
  - Object.create（原型式继承）

### Q3: 事件循环（Event Loop）？

**答案**：
- JS单线程，通过事件循环处理异步
- 执行栈为空时，从任务队列取任务执行
- 宏任务：script、setTimeout、setInterval、I/O、UI渲染
- 微任务：Promise.then、MutationObserver、queueMicrotask
- 执行顺序：同步代码 → 所有微任务 → 一个宏任务 → 所有微任务 → ...

```javascript
console.log(1);
setTimeout(() => console.log(2), 0);
Promise.resolve().then(() => console.log(3));
console.log(4);
// 输出: 1, 4, 3, 2
```

### Q4: var/let/const的区别？

| 特性 | var | let | const |
|------|-----|-----|-------|
| 作用域 | 函数作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | 提升并初始化为undefined | 提升但不初始化（TDZ） | 同let |
| 重复声明 | 可以 | 不可以 | 不可以 |
| 重新赋值 | 可以 | 可以 | 不可以（引用不可变） |
| 全局属性 | 挂载到window | 不挂载 | 不挂载 |

### Q5: 手写防抖和节流？

```javascript
// 防抖：n秒后执行，重复触发则重新计时
function debounce(fn, delay) {
    let timer = null;
    return function(...args) {
        clearTimeout(timer);
        timer = setTimeout(() => fn.apply(this, args), delay);
    };
}

// 节流：n秒内只执行一次
function throttle(fn, delay) {
    let last = 0;
    return function(...args) {
        const now = Date.now();
        if (now - last >= delay) {
            last = now;
            fn.apply(this, args);
        }
    };
}
```

### Q6: Promise的状态和方法？

**答案**：
- 三种状态：pending（等待）、fulfilled（成功）、rejected（失败）
- 状态只能从pending→fulfilled或pending→rejected，不可逆
- 方法：then、catch、finally
- 静态方法：Promise.all（全部成功）、Promise.race（最快的）、Promise.allSettled（全部完成）、Promise.any（第一个成功）

## 二、CSS

### Q7: 盒模型？box-sizing？

**答案**：
- 标准盒模型：width = content，总宽 = content + padding + border
- IE盒模型：width = content + padding + border
- `box-sizing: content-box`（标准）/ `border-box`（IE，推荐）

### Q8: BFC是什么？如何触发？

**答案**：
- BFC（块级格式化上下文）是独立的渲染区域，内部元素不影响外部
- 触发：float不为none、position为absolute/fixed、display为inline-block/flex/grid、overflow不为visible
- 应用：清除浮动、防止margin塌陷、自适应两栏布局

### Q9: Flexbox和Grid的区别？

| 维度 | Flexbox | Grid |
|------|---------|------|
| 布局方向 | 一维（行或列） | 二维（行+列） |
| 适用 | 组件内布局、导航栏 | 页面整体布局 |
| 内容优先 | 内容决定布局 | 布局决定内容位置 |

### Q10: 居中方案？

```css
/* 水平垂直居中 */
/* 方案1：Flex（推荐） */
.parent { display: flex; justify-content: center; align-items: center; }

/* 方案2：Grid */
.parent { display: grid; place-items: center; }

/* 方案3：绝对定位+transform */
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }

/* 方案4：绝对定位+margin auto */
.child { position: absolute; top: 0; bottom: 0; left: 0; right: 0; margin: auto; }
```

## 三、Vue3

### Q11: Vue3响应式原理？

**答案**：
- Vue3使用Proxy替代Vue2的Object.defineProperty
- Proxy可以监听对象属性的增删改、数组索引变化
- 依赖收集：track()在get时收集，trigger()在set时触发更新
- ref：基本类型响应式（通过.value访问）
- reactive：对象类型响应式（Proxy代理）
- 优势：无需$set，性能更好，支持Map/Set

### Q12: Composition API vs Options API？

| 维度 | Options API | Composition API |
|------|-------------|-----------------|
| 组织方式 | 按选项（data/methods/computed） | 按逻辑功能 |
| 代码复用 | mixins（命名冲突） | 组合式函数（清晰） |
| TypeScript | 支持差 | 支持好 |
| 适用 | 简单组件 | 复杂组件、大型项目 |
| 树摇 | 差 | 好（按需引入） |

### Q13: Vue3性能优化点？

- 编译优化：静态提升、补丁标记（PatchFlag）、缓存事件处理
- 响应式优化：Proxy替代defineProperty
- 打包优化：Tree Shaking、按需引入
- 运行时优化：虚拟DOM diff算法优化
- 代码分割：路由懒加载、组件异步加载

### Q14: Vue Router导航守卫？

- 全局守卫：beforeEach、beforeResolve、afterEach
- 路由独享：beforeEnter
- 组件内：beforeRouteEnter、beforeRouteUpdate、beforeRouteLeave
- 典型应用：登录鉴权、权限控制、页面离开确认

## 四、工程化

### Q15: Vite和Webpack的区别？

| 维度 | Webpack | Vite |
|------|---------|------|
| 开发服务器 | 打包后启动 | 利用浏览器ESM，按需编译 |
| 启动速度 | 慢（全量打包） | 极快（冷启动毫秒级） |
| HMR | 较慢 | 快（只更新变更模块） |
| 构建 | 成熟稳定 | Rollup，更快 |
| 生态 | 丰富 | 快速增长 |
| 适用 | 大型复杂项目 | 新项目、现代浏览器 |

### Q16: 前端性能优化手段？

**加载优化**：
- 代码分割、路由懒加载
- 资源压缩（gzip/brotli）
- 图片优化（WebP、懒加载、CDN）
- 预加载/预获取（preload/prefetch）
- HTTP缓存策略

**渲染优化**：
- 虚拟列表（长列表）
- 防抖节流
- 减少重排重绘
- requestAnimationFrame
- Web Worker处理大计算

**指标**：FCP、LCP、CLS、TTI、TTFB

## 五、浏览器

### Q17: 从输入URL到页面渲染的过程？

1. DNS解析（域名→IP）
2. TCP连接（三次握手）
3. TLS握手（HTTPS）
4. 发送HTTP请求
5. 服务器处理并响应
6. 浏览器解析HTML构建DOM树
7. 解析CSS构建CSSOM树
8. 合并为渲染树（Render Tree）
9. 布局（Layout）：计算位置大小
10. 绘制（Paint）：像素渲染
11. 合成（Composite）：图层合并显示

### Q18: 跨域解决方案？

- CORS（后端设置Access-Control-Allow-Origin）
- 代理服务器（开发环境Vite/Webpack proxy）
- Nginx反向代理
- JSONP（仅GET，已淘汰）
- postMessage（窗口间通信）
- WebSocket（不受同源策略限制）
